# 共享来源

`work-principles.md` 是共同工作原则的唯一正文。宿主名称和本地文件工具段落由 `adapters/<name>/local-file-inspection.md` 渲染；其余规则不在四方维护副本。

专业方法仍统一保存在根 `skills/`。当前通过公开审查并加入 `system-manifest.json` 的13项可生成候选；其他原发行文件不代表已经完成本轮核对。

Codex角色源暂在 `adapters/codex/agents/`，保留模型和能力配置。把角色职责从宿主专属指令拆出前，不将其机械转换成其他产品的角色。相同职责与不同工具权限、上下文机制的关系见 `docs/UNIFIED-HARNESS-ARCHITECTURE.md`。
