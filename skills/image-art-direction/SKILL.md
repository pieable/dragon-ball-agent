# 绘图创作与艺术指导

把绘图模型作为有视觉创作能力的协作者：交清作品要起什么作用、不可改变什么，把开放的视觉选择交给它发挥。调用方负责理解用户、提供材料、选择方向和核验作品。本 Skill 指导调用方组织工作；绘图模型实际只收到传入的提示与图片，不能假定它读过项目、对话历史或全局 `AGENTS`。

## 用户审美偏好与首稿必传要求

- **审美排除项（须实际传入创作提示与委派材料）**：用户不喜欢照片式写实的人物、场景、物品和材质，也不喜欢明显幼儿化的卡通；对整体零碎、形体被细条和断片拆散、细密杂纹堆砌的画面有明确反感。这是审美偏好而非仅限技术伪影：即使主体尚可辨认、没有重影，密集破布条、碎边、亮斑和纹理仍可因整体观感过碎而不予采用。除非用户当前明确选择此类密集或破碎风格，不以“有意的手绘感/破损造型”覆盖这项偏好。真实照片可作参考或事实依据，呈现真实证据时保留其真实性。
- **画面完整性要求（首稿及后续素材生成前即传入，不等用户指出“很碎”才加入）**：默认追求完整连贯的形体、连贯明暗和有主次的细节——主体轮廓与动作完整可读，明暗和色块组织连贯，细节服从形体、材质和视觉主次，避免无结构碎纹、零碎亮斑和装饰把画面切散。该要求描述观感和用途，不强制所有作品改成平涂、少细节或某一种画风；将这些审美排除项与完整性要求明确写入提示和参考材料，其余风格选择按作品用途交给绘图模型发挥，用户当前的明确要求优先。

## 日常工作中的视觉协作

- **主动参与但按作用选用**：构思方案、解释对象与关系、比较体验、制作报告和演示时，主动判断生图能否解决具体视觉表达问题，有用时即调用（不等用户点名，也不必等文字页面写完才补图）；调用频率由实际作用与反馈决定，不以出图次数为目标。
  - **整页视觉稿**：网页、教学与报告页面**只有在整体美术或新视觉身份是作品关键且方向仍开放时**，才默认先让生图模型画出完整页面视觉稿（把布局、美术和内容表达一起设计）。
  - **普通报告与精确图示**：普通信息报告按内容关系组织，以成熟、朴素的排版清楚交代信息；精确路线图沿用 Mermaid 或程序化绘图，不套用整页美术流程。
  - **局部与辅助探索**：首图、横幅、风格稿、设计拆解稿、独立解释图或可组合素材可在解决具体视觉问题时单独采用；已有可靠素材和精确程序图适用时直接复用或结合生成图。
- **第一印象与理解体验**：对需要整体视觉设计的成果，把第一眼吸引力、完成度和理解体验作为目标（不了解背景的人能否感到值得进入、辨认主体和主要行动）。视觉方向在布局与素材展开前形成，功能原型可并行验证；轻量制作优先缩小内容规模、减少无关装饰，保住所展示范围的视觉质量。减少理解负担是判断标准，装饰数量和图像面积不作为目标。

## 交代意图，保留创作空间

- **查核原始材料与独立简报**：从上下文取得用途、受众、主体、期望感受、展示环境与关键限制；查看原文、实物/人物资料、使用版面等原件，不凭转述画图。既有角色、品牌或产品需保真时，先查看原始身份参考并将影响辨认的外观与参考图交入，不靠模型凭名称回忆。只补问会改变作品方向的未知；方向开放时先出可看方案帮助判断。整理会改变视觉判断的用途、读者、情境、阶段、内容关系及用户反馈随简报交入（按当前作品筛选，不堆入无关历史，也不只列名词或排版命令）。
- **界面/信息稿必传约束**：信息类作品需交清读者看完要理解、判断或执行什么，主要结论、必要条件及证据作用。制作界面或信息页面视觉稿时，明确传入：**“避免不必要的次级标签和说明，让布局本身解释关系（Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining.）”**，仅保留辨认内容、关系与操作所需的标签，成图与 HTML 实现均据此检查。
- **分清硬约束与自由空间**：简报区分必须满足的条件（事实、身份、文案、关系、交付尺寸、透明背景等）与可自主发挥的空间（构图、视角、光影、配色、材质和细节），说明所需成熟度。与美术无关、可在落地时修正的错字、日期、价格、业务规则和交互细节由调用方与实现者处理，不为这些细节反复重画；但会改变画面含义、视觉结构或难以后期调整的条件须在创作前交清。
- **以效果交接，不作像素级微操**：新图和修改均描述观众应注意什么、感受到什么及哪里影响用途或观感，具体画法和调整幅度交给绘图模型；即使精修也不由调用方规定“眼睛放大多少像素、五官移动多少百分比或每条线位置”（用户明确指定的数值、尺寸、准确文案和事实关系照实传入）。转述反馈时区分用户感受与原因假设，保留“可能”“似乎”等不确定性，不把猜测写成确定缺陷，允许绘图模型在目标和保留项内选择解决方式。需要简报示例与方法依据时读 [创作交接示例与依据](references/briefs-and-evidence.md)。

## 主动发展风格

- **视觉语言与参考图分工**：按用途、偏好和既有体系采用内部协调的视觉语言；需要引导时用媒介、造型、色彩、光线、笔触、材质或节奏中真正相关的线索，不堆砌冲突风格词。缺少方向时查看成熟作品或作品集画面本身；参考图分别标明用于**身份、风格、构图还是编辑对象**，指出保留与可变部分，无需把图像已表达清楚的风格翻译成长文。
- **更新画风与小样先行**：用户要求更新画风或了解当代方向时，查看近期有可追溯出处的成熟作品，比较线条、形体、色光、材质与构图的实质差别（人物年龄、服饰、题材与画法分别判断，不把新近、流行或纹理更多当成品质更高）。既有角色身份参考与新画法参考分开；先用真实主体小样检验变化，再扩成整套。若小样仍沿袭旧画法，检查旧生成图是否限制了变化，必要时从干净身份与独立画法参考重新创作，而非反复强化原底图。
- **多候选探索与结构控制**：重要或未定方向用概念、构图或媒介有实质差异的候选比较（按未知选草图、剪影、明暗稿或完整出图）；选定后保留可复用参考与视觉决定用于系列一致性，局部精修暴露方向问题时可返回探索。文字难说清或反复生成不对时，补足参考图、照片/草图/三维姿态空间参照，或在工具支持时用选区、蒙版和结构控制限定变化（局部修正保留关联身体部位、接触对象与光照上下文）；按需读取 [专业方法与工具](references/methods-and-tools.md)。

## 看图后继续指导

- **原始尺寸与使用尺寸双检**：打开实际产物，在**原始尺寸与实际使用尺寸**下检查（首稿也须完成，不能只看缩略图或内容齐全就采用）。先看用途、情绪、整体主次与第一印象，再查人物身份、姿态与头颈肢体衔接、透视与接触关系、文字事实、透明边缘、主体轮廓、明暗体积和材质细节（风格化夸张按该风格判断，同时排查非预期错位、断裂或含义变化）。
- **重点排查三层“碎”**：
  1. **形体被切碎**：衣料、头发、建筑等被过多细条、锯齿或断片拆开，主体轮廓和动作难辨认（如整件衣服画成破布条）。
  2. **明暗与纹理被切碎**：无结构碎纹、细密亮斑、斑块、重影或半透明条带吞没边界、割裂体积，或让不同材质变成相似杂纹。
  3. **构图与注意力被切碎**：人物、背景、特效和装饰到处同样密集、锐利或明亮，缺乏主体、次要部分与安静区域的区分。
  *破损造型、复杂纹样或粗犷笔触仅在符合当前有效审美方向且保持形体与层级时采用；不把“手绘感/丰富细节”当放行理由，也不把去碎处理成单纯模糊、抹平或删光细节。只有整体吸引力、形体完整性与使用尺寸层级达标才标为已采用（未达标时暂缓依赖该美术方向的制作，独立功能继续；核验由 agent 主动完成，不留给用户找问题）。*
- **多轮退化、条带清理与底图管理**：
  - **条带与伪影清理**：严查半透明条带、叠影及多轮编辑加重的纹理。将可见位置、观感影响和干净参考交给绘图模型自行选择清理或重建画法，按 [专业方法与工具](references/methods-and-tools.md#纹理伪影的检查与清理) 对照前后图核验。修复无效或条纹已广泛融入画面时，**停止沿退化版本叠加编辑**，回到干净底图合并有效修改，或保留身份与设计依据重绘（问题图只作设计参考，不继承其纹理）。
  - **底图选择与局部合成**：方向有效而局部有问题时，选画质可靠且符合已确认设计的版本作底图，**不默认使用最新输出**；整体方向不合适时重新构思，不靠不断追加限制词维持失败方案。连续编辑时对照底图检查修改处与不变区（区分原有笔触材质与新生伪影）；工具支持且权限允许时只合成合格修改区域并检查衔接，不把“其余不变”的提示当像素保护。清理后同时核对画质与设计保真，不以变亮、变平滑代替修好，不丢失已确认细节、表情和角色特征；是否继续重绘由实际变化判断，不设统一次数上限。
  - **成因归因边界**：用户对多轮退化的观察作为持续检查依据；但“每次多轮修改必然出现”、OpenAI 水印或扩散机制等成因判断仍需证据，未知成因保持未知，不把猜测写进修图要求，也不凭版本号、文件名或单张图断定退化过程与模型机制。
- **放回真实场景核验**：将素材放回真实页面、封面或使用场景，按实际尺寸和背景检查小尺寸识别、裁切、对比、系列一致性及是否喧宾夺主。重要风格取舍用可见对照请用户反馈，技术和形体缺陷由 agent 主动处理。

## 按用途制作可组合素材与落地网页

- **可组合素材拆分**：需要跨页面复用、独立替换或交互变化时，让绘图模型分别制作角色、物件、背景、装饰等素材，再由页面或合成工具组织成品。根据复用与变化的边界拆分，保留姿态、接触和光影紧密关联的整体；画面完整性偏好不等于禁止工程资产拆分，也不以拆得越碎或生成得越多为目标。生成的贴图不自动构成可用 UV 或模型资产，按目标格式和实际组装验证。先用代表素材确认视觉语言，后续共享参考与风格约定，按实际用途扩充。
- **素材交接与组合检查**：向绘图模型交清素材将放在哪里、与什么组合；**按需**统一视角、比例、光照、笔触、边缘和透明背景，预留裁切与重叠空间。把素材放进真实组合检查，修正不协调的部分。整张视觉稿仍可帮助确定整体方向，独立素材承担实际使用，两者可以配合。

- **从整页视觉稿到网页**：当整体美术或新视觉身份是作品关键且方向仍开放时，以真实代表内容生成完整页面视觉稿（涵盖页面入口、主要内容区、导航与操作位置、图文层级和区块衔接；长页面或多页面用整体稿与衔接的分区/页面稿覆盖，不为塞进单张图省略内容或缩成无法阅读的小字）。采用后作为前端整体设计依据：前端读取 [frontend-design](../frontend-design/SKILL.md) 承接有效构图与美术（不只取走插图配色另排页面），将准确文字、数据尺度、引用和交互落实为可核验、可编辑、可操作的页面元素，不用整页位图替代网页。具体简报、交接与验收按 [网页视觉稿落地](references/image-to-web.md) 执行。

## 工具与交付

- **工具选择与能力边界**：生成或编辑位图时读取并使用现有 `imagegen` Skill，默认使用内置绘图；调用方式、参考图与保存规则由其承载。只使用当前工具实际提供的能力，不把其他产品的风格参数或接口字段写成可用功能。
- **素材复用与媒介分工**：优先复用适配的已有素材与成套图标。人物、场景、质感和艺术表达适合绘图；需要精确、可编辑、可缩放的图标、连线、图表或界面元素，可用成熟矢量资产与程序化实现。按质量和使用条件组合，保持整体视觉语言协调。
- **项目保存与效果评估**：项目素材保存到项目中并接入实际成品，保留必要的源图、最终提示和版本关系。向用户展示作品，简短说明关键视觉选择及尚需决定的事项。评估方法是否改善时比较同一任务的实际产物；一次出图不等于证明某种提示方式普遍更好。需要组织简报或查明这些方法的依据时，读 [创作交接示例与依据](references/briefs-and-evidence.md)。
