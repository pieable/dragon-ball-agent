# 通用搜索与取证

用于选择搜索路线、发现来源、判断证据用途与覆盖范围。根据当前任务读取 [研究结构与搜索方法](research-structure-and-search.md)、[搜索资源表](search-resources.md) 或 [代码来源表](code-research.md)。

## 先辨明搜索用途

| 当前目的 | 起点与扩展方式 | 要交回什么 |
| --- | --- | --- |
| 理解陌生问题、发现路径 | 教材、综述、专业工作流、代表与失败案例；提取领域术语，沿方法和关系扩到其他领域 | 问题结构、实质不同的解释或路线、改变理解的材料与未知 |
| 理解方法怎样工作 | 原始论证、实验协议、设计与操作记录、源码、实施和失败案例 | 机制、输入输出、操作、成立条件及可迁移部分 |
| 核验已知主张 | 查谁或哪个系统产生原始记录，按对象、机构、文件类型和版本定位 | 直接支持或反驳主张的证据、边界与冲突 |
| 尽可能列全候选 | 相应领域的索引、目录、注册表、数据库、feed 或日历，辅以网页搜索 | 可说明的候选范围、分页与筛选覆盖、尚未检查的入口 |

探索时可以先用社区经验、专业综述或相关案例发现问题；进入结论核验时追到适合该主张的原始材料。发现入口与证据来源各有用途，不因某来源不能直接证明结论就过早排除其发现价值。

## 按主张判断证据用途

| 角色 | 常见材料 | 判断依据与边界 |
| --- | --- | --- |
| 直接记录 | 法规、披露、统计与方法、标准正文、源码、原始论文和数据、当事方声明 | 直接覆盖什么对象与行为；当事方材料可证明其宣布或报告的内容，效果与解释另需检验 |
| 独立核验或综合 | 独立调查、复现实验、系统综述、公开方法与引用链的研究 | 方法是否适合问题、样本与来源是否独立、时间与利益关系；综合性结论可能更适合由高质量综述支持 |
| 可追溯整理 | 专业媒体、行业文章、百科、署名专家文章 | 用于背景与术语，沿引用定位支撑重要主张的材料 |
| 候选线索 | 搜索摘要、AI 摘要、聚合页、转载、论坛与社交帖 | 用于发现，摘要和转载追到原页；原帖可直接证明作者报告了什么，推广到群体仍需其他证据 |

这是对当前主张的判断，不给网站永久排序。来源的直接性与研究质量分别核对：原始研究也可能方法薄弱，多篇报道也可能共用同一消息源。

## 哪些系统产生原始记录

| 主张 | 优先定位 | 必查条件 |
| --- | --- | --- |
| 产品功能、价格、可用性 | 产品文档、定价与更新记录、状态页 | 版本、地区、账户类型、查询日期 |
| 法律、政策、司法决定 | 主管机关正式发布、公报、法院文书 | 管辖地、生效日期、修订或废止状态 |
| 人物职务、组织关系 | 组织名录、任免公告、监管披露 | 任职起止、同名对象、法律实体 |
| 公司与财务数据 | 交易所和监管披露、财报、招股书、工商登记 | 报告期、主体、币种、指标口径 |
| 学术与技术结论 | 原始论文、数据、代码、实验方案及适当综述 | 版本、样本、方法、复现、勘误与撤稿 |
| 统计与经济指标 | 数据生产机构的数据集和方法说明 | 定义、统计期、修订、季调与缺失值 |
| 新闻事件 | 公告、文件、讲话、现场记录，独立报道补背景 | 事件发生时间、发布时间、证据形成时间 |
| 健康与安全判断 | 监管机构、专业指南、系统综述与相关原始研究 | 人群、地区、证据质量与更新时间 |
| 地点、营业、交通状态 | 场所或运营方、政府与交通机构公告 | 地点、日期、临时变化；体验另查近期独立记录 |

## 搜索、核验与补查

已知对象和发布方时，使用准确名称、文件编号、机构域名、站内查询或数据库筛选。未知术语和发布方时，先取得相关样例和领域词汇，按 [研究结构与搜索方法](research-structure-and-search.md) 扩展查询。不同引擎、网页与 API 的语法、索引和权限分别检查。

打开原文，记录实际覆盖的主张和材料范围。搜索摘要及引用片段用于定位；正文不可得时，明确仅取得摘要、元数据或二手转述，按结论重要性补找出版方、机构仓储、作者版本或其他独立材料。

冲突出现时先比较对象、定义、时间、版本和地区；边界不同分别陈述，边界相同再比较方法、直接性、更正和利益关系。结论依赖解释、来源有直接利益或行动后果重要时，寻找适合该主张的独立检验。

保留入口实际状态：成功取得什么、查询与过滤范围、分页是否走完、访问失败、需要登录/浏览器/适配器或尚未检查。程序成功与入口返回空结果都不能代替覆盖判断。重要分支的查询、后续方向和未解决缺口进入项目研究记录，不需要保存每次无意义尝试。

多人枚举与核验时明确候选和来源责任，避免无目的重复；来源路线不同、异常空结果或需要独立复核时可以交叉检查。实际搜索者读取对应来源表，交回候选、证据、覆盖与缺口，研究负责人按主 Skill 核对决定性原文。

“全部”“没有”与时间窗内完整清单需要可说明的候选空间和实际检查。开放探索按主 Skill 的发散与收敛条件推进；单一事实已有适用证据且关键冲突解决即可结束。交付给出直接链接、必要日期、证据支持的范围和仍会改变判断的缺口。
