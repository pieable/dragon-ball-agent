# 问题与方法的深入研究

用于理解一种思想、概念、标准或专业做法为什么成立，以及怎样借鉴。已有可靠解释可以直接复用。历史追溯的投入取决于它能否解释当前疑点、区分不同做法或改变适用判断。

## 恢复问题与选择情境

从原始著作、工作记录、案例或版本差异中查明：实践者面对什么困难，已有做法为什么不足，当时具备什么知识、工具与可选路径。沿其实际讨论过或使用过的解释追踪选择，保留有竞争力却被放弃的路线及理由。研究者另外提出的替代解释单独标明，按相应证据检验。

把当时的问题与后来的用途分开。作者的自述、实际操作、同期批评和后续效果分别支持不同主张。按来源、形成时间、作者或编者的角色及修订关系核对材料。版本先后可以证明变化发生，解释变化原因还需要当时的理由、行为或能区分原因的证据。以当时可获得的信息理解选择，再依据当前任务评价其价值。

从历史会话判断 Agent 或 Skill 的作用时，核对当时实际获得的规则版本、正文与引用材料、可见范围及加载时点。缺少调用、使用旧版、输出截断、理解或选择失配分别保留证据。历史行为用于恢复失败情境，评价现行方法时另核对当前内容和适用条件；当时指导未知的部分保持未知，不据此指定当前 Skill 为原因。

## 追踪论证与实践中的变化

阅读核心论证时，追问每个转折在回应什么困难：哪项理由使旧解释不足，新的解释保留了什么，又新增了哪些条件。将结论放回完整推导中检查。某段正在提出的问题、作者暂时接受的模型或引用的异议，都可能在后文被修正。

研究方法时，沿真实案例追到实际工作：从什么原始材料出发，观察到了什么，使用什么工具或操作取得结果，结果怎样影响下一步选择。比较说明与实际产物、成功与失败情形，找出会改变做法的差异。材料只给出概括时，继续查实例、过程记录或实现。能够通过小样查明的技术问题，实际尝试并保留输入与结果。

“客观”“可靠”“简单”等标准需要通过实践辨明含义。找出采用该标准后，实践者具体保留、排除、修正或验证了什么，再比较同一工具用于不同标准、或不同工具服务同一目标的情况。例如同样使用摄影，保留个体的不规则细节与修整图像以呈现典型形态，会形成不同的研究对象。工具名称本身无法说明其判断标准。

解释一项变化时，根据材料检验思想内部的问题、技术条件、社会要求与个人选择各自的作用。选择能够解释变化且与反证相容的关系，保留仍有竞争力的解释。后继者可能解决了新的问题，不能用最终成功倒推原方案在所有方面都更好，也不能因一种方法被取代就抹去它仍有效的贡献。

## 从理解到当前任务的工作方法

选择要迁移的判断关系，写清当前任务中的对应对象及条件。实践者观察什么才能决定下一步，这个观察在当前环境里如何取得，什么结果会改变原有解释或行动，都是方法设计需要的内容。专业术语、操作名称和案例数量本身不足以回答这些问题。

先用代表性材料或实际任务的一段工作检验关键方法。核对它是否帮助发现原先遗漏的问题、取得区分解释的证据，或作出条件明确的选择。能由结构、数据校验或工具稳定承担的检查交给相应机制，解释材料和取舍仍依据原文与实际结果判断。例如范围检查能够发现遗漏的章节，却不能判断一段总结是否误解了作者。

解释方法如何形成，依据原始记录。判断它能否迁移，依据当前任务中的条件和试用。评价它是否更有效，按主 Skill 的外部检验要求取得可比较证据。新发现改变研究问题或材料相关性时，更新问题并回查来源。交付保留关键论证、实际操作、适用条件及未解决的冲突，使接收者能够继续设计或使用方法。

## 研究依据

- 柯林武德《历史的观念》第五编第二至四节：连续论证、问题与证据的关系、依据材料重思行动者的问题及选择。
- 库恩《哥白尼革命》第五章，印132–142、168–179页：原始问题、技术操作、继承的工具与后继问题的区别。
- Daston 与 Galison《Objectivity》第一章及印150–151页雪花案例：认识标准通过实践形成，同一媒介可以服务不同规范。
- 文德尔班《哲学史教程》绪论，印21–30页：资料核实、思想形成的解释与价值评价各有工作；形成过程可能涉及多种因素。
- [pstack 的原则修订](https://github.com/cursor/plugins/commit/e5136d82418d2db3165ea1050d17577cd618cc05)：从限定特定机制改为说明选择依据。以上来源帮助形成研究动作，当前方法的使用效果由实际任务检验。
