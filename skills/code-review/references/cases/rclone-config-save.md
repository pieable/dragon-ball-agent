# 配置保存的两次rename中断窗口

记录时点：2026-10-14。Issue于2026-10-12创建，最早引入日期未确认。

rclone在保存配置时先将原文件移到备份名，再把临时新文件改为原配置名。报告者在文件操作之间终止进程：两次rename之间的默认配置路径消失，备份和临时内容仍在，命令无法找到已有remotes，需要人工恢复文件名。

报告有操作点kill和再次运行记录。候选补丁改为直接替换原路径；新增目录边界测试只验证配置路径已经是目录的情形，没有直接模拟kill窗口。记录时补丁尚未合入。报告明确掉电和多进程竞争未测，Claude参与准备报告。

用于辨明中断后的持久状态、恢复入口，以及每项证据真正覆盖的失败条件。

来源：[issue #10076](https://github.com/rclone/rclone/issues/10076)、[候选补丁](https://github.com/aniketatgithub/rclone/commit/ba623597bdb0467444eccdaeffe8f81be147f737)。
