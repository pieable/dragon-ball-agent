# 已登记的样式依赖仍在加载

记录时点：2026-10-14。Issue于2026-10-05创建，最早引入日期未确认。

Vite预加载helper插入样式link时立即写入`seen`标记。首次动态导入等待load事件；另一次重叠导入看到该标记便提前返回，页面短暂呈现无样式内容。

修复将进行中的CSS Promise保留在共享状态中，让后来的调用共同等待，并增加等待、去重和错误传播测试；PR于10月8日合入。报告中的AI解释属于问题分析活动，致错代码来源未知。

用于区分登记、进行中、成功及失败，并追踪各消费者实际等待的完成条件。

来源：[issue #23652](https://github.com/vitejs/vite/issues/23652)、[修复PR #23662](https://github.com/vitejs/vite/pull/23662)。
