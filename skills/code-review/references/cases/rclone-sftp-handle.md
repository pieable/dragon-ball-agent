# 失败上传后的句柄与连接池

记录时点：2026-10-14。Issue于2026-10-03创建，最早引入日期未确认。

SFTP上传因磁盘满失败，错误路径先将连接归还池，再删除部分文件，全程漏掉远端句柄关闭。目录中看不到文件，但服务端空间仍被已打开文件占用；长生命周期进程的后续上传失败，进程退出后空间才释放。

报告者用20MB tmpfs承接30MB上传，对照旧版本与beta，修复后空间释放且同连接池下的后续上传成功。补丁在错误返回前关闭句柄，已合入；该提交没有新增自动回归测试，主要行为复验来自报告者的同场景对照。

用于追踪失败路径上关闭、删除、归还与下一次使用的顺序。

来源：[issue #10033](https://github.com/rclone/rclone/issues/10033)、[修复提交](https://github.com/rclone/rclone/commit/d545615c1649fe7946acc344ae4c494694c05015)。
