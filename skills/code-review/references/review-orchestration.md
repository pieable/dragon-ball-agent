# 审查组织与工具

用于大变更分派、工具辅助审查，或判断一种审查方法是否有效。小改动直接完成，不另建任务系统或强制增加审查轮次。

## 范围与上下文

从准确基线、候选与用户指定范围取得实际变更，核对新增、删除、改名和未跟踪内容。保留工具排除的对象及理由，将约定范围与工具选中集合分开；相关测试、配置、生成来源和删除影响不能只因默认过滤而消失。截断、大文件或执行失败需要分段补读、改变取证方法，或明确保留缺口。

分工按需要共同判断的关系组织，例如接口与消费者、数据格式与迁移、实现与测试。给执行者原始要求、候选、相关材料入口和未决问题，允许沿证据查到组外。目录、扩展名和自动分组可作起点，不能代替实际依赖判断。跨组连接由负责人明确归属并核对，不让每组局部通过代替集成成立。

使用现有任务记录或工具输出区分已审、排除、未完成及原因，收尾对照最初范围和调查中新增的受影响对象。文件已读或任务已结束只证明相应动作完成；问题是否找全、行为是否成立仍看证据。详细覆盖供 agent 接续与核验，用户正文只保留影响交付判断的缺口。

## 规则与工具

按变更机制选择风险专题，再按语言、框架与版本补必要的专业提醒。先复用项目检查、编译器、类型检查、lint、安全扫描及成熟审查工具。外部规则先核对适用条件和现有承接，不整库复制；并发问题查实际调用方式，性能问题查规模与热路径，安全问题查输入来源和权限边界。

规则由程序选择时，查看实际匹配来源、优先级和替换或合并结果，确认项目约束仍生效。确定性能力用于整理范围、核对状态及定位，模型负责调查语义与影响。报告前核对当前候选中的路径、原文片段和行号；能匹配代码不等于缺陷成立，位置不明时继续定位而不猜测。

需要工具辅助的范围预览或规则解析时，可评估 [Open Code Review 委托模式](https://github.com/alibaba/open-code-review/blob/375f64cd6f67a48a135da83cfcf59c52669a09cb/skills/open-code-review-delegate/SKILL.md)：`ocr delegate preview` 提供文件与排除原因，`ocr delegate rule` 提供匹配规则，宿主 agent 承担审查。使用前核对当前安装、版本、过滤结果和适配；它是可选工具，不是必装依赖。默认排除测试、删除或超限 diff 的策略不直接作为本地审查范围，缺口由当前任务补足。工具退出成功不代替检查完整结果；委托模式的完成清单仍需宿主落实。

## 发现的复核

把发现交给另一执行者核验时，交接准确对象、触发条件、预期与实际差异、依据及已知反证。复核者取得必要原始上下文后判断；缺少材料时补查，无法确认时保留未知。已证明的反例用于纠正发现，位置错误用于重新定位，不能用上下文较少的一次判断抹去重要疑点。按实际风险选择独立复核，不固定每条评论都增加一个 agent。

## 检验方法的效果

更换提示、模型、工具或分工后需要评价效果时，复用项目历史故障与真实变更，或 [AACR-Bench](https://github.com/alibaba/aacr-bench) 的固定 base/head、原始仓库及标注材料。保持比较范围、输入和环境可比，区分缺陷类型及所需上下文，分别观察确认的问题、误报、已知问题漏检、定位和投入。标注并不穷尽所有缺陷，新发现回查原始证据；模型裁判的结果也需要检查。

重点检查是否捕获真实使用错误和跨文件问题，以及低噪声是否以遗漏重要问题为代价。公开成绩不能直接作为本项目改善证据。提示词行为比较沿用 [真实任务中的行为验证](../../write-instructions-zh/references/behavior-validation.md)，已有适用证据继续使用，不因普通措辞调整启动完整基准。

## 方法来源

- [规则匹配](https://github.com/alibaba/open-code-review/blob/375f64cd6f67a48a135da83cfcf59c52669a09cb/pages/src/content/docs/en/review-rules.md)、[原文定位](https://github.com/alibaba/open-code-review/blob/375f64cd6f67a48a135da83cfcf59c52669a09cb/internal/diff/resolver.go)。
- [评论过滤的证据边界](https://github.com/alibaba/open-code-review/blob/375f64cd6f67a48a135da83cfcf59c52669a09cb/internal/config/template/prompts/review_filter_task_user.md)。借鉴限制复核者推断权限，不继承特定类别无条件放行的规则。
