# 接口、配置、权限与集成

当变更影响公共行为、配置、权限、消费者或发布入口时，同时核对提供方、权威边界和实际使用路径。

**接口、配置或权限：** 同时追踪提供方与所有调用方。确认默认值和公开能力有当前消费者或明确合同支撑，并沿拒绝路径检查所有可执行入口。显示层限制不能代替权威服务边界。

**加载、注册、CLI 或外部集成：** 关注实际发布入口，而不是只测试手工组装的函数。检查导出、配置、注册和失败诊断。

追踪默认值、特性开关、环境变量、旧状态和升级路径怎样改变可达行为。原来很少触发的实现成为默认路径时，核对它原有的消费者和环境假设。调用方、插件、下游依赖、实际安装包或发布配置没有出现在diff中，仍按影响检查其兼容性。

对拒绝和权限路径，恢复主体、对象、操作和授权的真实合同，核对每个入口执行的权威检查。用户预期、作者解释和已确认产品决定分别取证，再判断候选是否违反当前要求。

验证工具分别覆盖解析、类型、链接、加载和真实操作。按声明需要观察消费者实际经过的边界，以及它得到的结果和失败诊断。

需要本包正确但下游链接失败的具体对照时，查看[Tauri构建案例](../cases/tauri-downstream-link.md)。
