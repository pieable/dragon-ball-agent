# 输入与跨层表示

当输入的使用方式、编码、规范化、数值宽度、对象布局或跨语言边界改变时，沿完整转换与消费过程检查。

按接口允许的输入形状追踪使用语义，包括是否可重复遍历、是否借用、何时被消耗，以及错误发生前已执行的副作用。多个消费者或分支复用同一输入时，核对它们取得的数据是否仍符合合同。

同一对象在创建、存储、列表、查找、读取和删除中应保持可对应的身份。比较不同大小、阈值、平台或重试路径使用的编码与规范化规则，确认往返操作能定位原对象。

跨语言接口核对参数宽度、符号、长度单位、终止约定和所有权。类型转换改变特殊值含义时，继续检查接收方实际执行的分支。证明或静态类型成立后，还要追踪运行时表示、共享、读取和释放是否使用相同布局。

需要合法Iterable被重复消耗与失败残留的具体例子时，查看[sqlite-utils案例](../cases/sqlite-iterable.md)。
