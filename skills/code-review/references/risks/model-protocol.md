# 模型可见协议

变更涉及模型指令、工具参数、结果通道、上下文恢复或诊断时，按实际传递的行为协议审查。

**agent prompt、工具 schema 或 transcript：** 把模型可见文本和参数当作行为协议，核对模型实际收到的提示、schema、结果和诊断，并用 snapshot 或真实链路验证适用部分。

沿生成、装配、传递、截断、恢复和消费路径核对指令、参数与结果。文件存在、字段配置正确和发送端成功，各自只能支持相应阶段；关注接收模型是否实际取得当前版本、错误正文和任务状态，并检查它据此产生的行为。

有多个结果通道、包装层或异步通知时，核对权威结果是否会被警告、旧状态或空值替换，失败是否仍被发布为成功。规格或工具接口变化后，同时核查模型可见合同、实际实现和验证输入。

比较提示词或模型行为时，核对任务输入、环境及模型设置是否可比，单独标明作为研究因素改变的条件。检查正常任务之外是否附带了评测身份或候选优劣暗示，评分端是否使用匿名标签。按 [`write-instructions-zh` 的真实任务验证方法](../../../write-instructions-zh/references/behavior-validation.md) 核对实际输入、配置、输出和执行记录。候选模型或评审模型的偏好投票不能替代实际执行证据。
