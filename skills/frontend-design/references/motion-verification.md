# 动画过程检查

用于控件微交互、状态/布局过渡、拖动和演示动画的检查。AI 使用稀疏截图时容易漏掉短暂异常；把运动过程转换为带时间戳的轨迹与图像序列，再按发现定位局部。项目已有等价工具时沿用，缺少时使用本 Skill 的采集工具；不要只发出“播放检查”指令后按起止画面验收。

## 取得可判断的时间过程

从项目正常入口和代表性真实内容出发，先明确这次操作应改变什么，以及运动中应保持的关系，例如菜单锚点不漂移、按钮文字不重叠、列表邻居随新增空间移动。按实际场景选择检查范围，默认不把每个控件扩成全站动画审计。

1. **先安装采集，再触发真实事件。** 复用已有浏览器负责人和 Playwright 页面，通过真实点击、输入、拖动或异步状态变化触发。记录浏览器、视口、目标根、操作序列、时钟模式和采集窗口；根节点应包含受影响邻居，别只圈住移动元素。
2. **采集轨迹。** 在浏览器动画帧回调中记录时间、可见元素的位置/尺寸和内容变化。定位突然位移等候选，并结合轨迹核对邻居同步和弹层锚点。查看上下文，区分正常瞬时反馈、预期布局变化与错误。阈值只用于发现可疑点，不作为产品动效标准。
3. **采集图像序列。** 在可复现的同一操作下，按过程与异常时间取得带时间戳的图组；短过程加密、局部放大或慢放，覆盖触发后、运动中、落位与退出。检查像素中的文字、透明度、图层、遮挡、边缘和内容交接。采集量随需要确定；仅缩小整张大图组会看不清时，分别打开关键帧或局部。
4. **单独核对真实时间。** 截图与大量 DOM 测量会影响采样，受控时钟和慢放也会改变运行条件。轨迹与截图优先分开重放；真实速度检查输入响应、卡顿、重复姿态后突跳及最终状态。需要性能判断时结合项目现有浏览器性能追踪与目标设备，说明观测手段本身的开销。

同一元素中途文本或图标替换可能几何不变；图层合成、字体栅格化、Canvas/WebGL 或视频内部变化也可能不反映在 DOM 轨迹中。按当前对象补充图像/像素或现有媒体、性能工具，不以几何无异常关闭这些问题。

## 连续操作与状态变化

对本次涉及的变化选择实际会发生的打断：运动未结束再次点击或改目标、开到一半关闭、请求结果在运动中到达、拖动中撤销。检查从当前画面继续、业务结果正确、退出后的命中与焦点正常；不为动画锁死原本应可用的操作。按依赖检查文字换行、内容增长、窗口宽度变化和字体加载。

系统减少动态效果时核对真实当前状态及可操作性；涉及自动播放、循环、后台暂停或返回时，再检查离屏、隐藏标签页、返回与重播。测试条件来自当前功能，不将示例时长、尺寸或平台习惯写成全局产品限制。

## 工具入口

本 Skill 的 `scripts/motion-capture.mjs` 提供普通 DOM 采集适配，复用 Stageshow 固定版本的几何记录和异常分析。使用项目已有 Playwright 和浏览器连接，将当前 `page` 传入；工具不安装依赖、不另开浏览器，不依赖 React `Stage`，不执行宣传图构图规则。

使用提供 Playwright Page 的现有脚本或浏览器工具代码入口加载模块；仅有截图/页面执行接口时，先核对该工具能否接入采集，不为取得 Page 另起一套已登录浏览器。当前适配只进入指定根的普通 DOM，iframe、Shadow DOM、伪元素与媒体内部画面按实际工具能力另行取得证据。

```js
import { captureMotion, writeMotionReport, captureFilmstrip } from '/实际skill路径/scripts/motion-capture.mjs';

// 在已打开的真实页面中采集轨迹；此处数值只是这个操作的采集窗口。
const trigger = async page => { await page.getByRole('button', { name: '展开详情' }).click(); };
const trace = await captureMotion(page, {
  root: '#details-region', durationMs: 1000, trigger,
  label: '展开详情', mode: 'realtime',
});
await writeMotionReport(trace, '/当前项目/work/motion/open');

// 先经项目正常路径恢复相同起点，再独立重放并取得图像。
await captureFilmstrip(page, {
  root: '#details-region', durationMs: 1000, intervalMs: 50, trigger,
  outputDir: '/当前项目/work/motion/open-images', label: '展开详情', mode: 'realtime',
});
```

Windows 的动态 `import()` 使用 `pathToFileURL(absolutePath).href`；其他工具环境按正常模块加载方式接入。`durationMs` 与 `intervalMs` 显式传入并按实际过程决定，示例值不是产品要求。轨迹报告保存原始 JSON 和 HTML；图组保存带实际采样时间的 PNG、JSON 与可浏览 HTML，打开关键 PNG 查看像素。采集 API 以模块导出及脚本内注释为准。

`mode` 只声明当前时钟条件，不会自动接管页面时间。受控/慢放需要项目现有时钟或浏览器能力另行配置并记录；只有实际参与受控的动画能按受控时间解释。真实数据或页面状态在两次运行中会变化时，先固定可授权的测试数据或记录差异；避免为了获得图组重做不可重复的提交、发送或付款操作。

## 判断结果与交接

- 轨迹无发现、图像中途检查、真实操作结果和真实时间性能分别报告。正常瞬时变化可保留，命中候选按实际证据处理；不能为消除告警把内容藏掉或给整片元素加忽略标记。
- 记录过短、目标缺失/失联、采样过稀或存在空缺时，将受影响部分标为采集不完整，补采或改用适合的工具。自动工具输出无发现只覆盖已观测属性；几何采样回调并非显示器实际呈现的每一帧。
- 未取得连续播放感知时，说明已检查的图组、轨迹与剩余观感；不要求用户替 AI 完成所有常规检查。像素闪烁、节奏或设备帧率若仍影响交付，继续取得对应证据，必要时把具体未验项交给用户判断。
- 保存原始轨迹/报告、时间图组及关键帧、操作与复现入口，并在项目现有检查记录登记。修复后重查受影响过程，最终证据对应当前候选。
