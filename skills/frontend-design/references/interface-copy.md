# 界面文字与页面接续

撰写、修改或审查界面文字时，使用 [写作与文字审查](../../writing-zh/SKILL.md)，由其承载读者、目的、双方关系与阅读方式的判断，以及表达、标题和写后审查方法；标题问题读取其[界面文案审查](../../writing-zh/references/interface-copy.md)。报告页面支持自主定位，标题直接呈现具体内容，避免以“先看……”等阅读指令代替。操作控件与流程步骤按真实动作命名。同一连续任务已读且仍有效时沿用。

前端负责人提供当前页面、真实文案、操作与状态，把文字审查结果落实到页面。反复用说明告诉用户去哪找、什么属于一组或是否操作成功时，检查相应的布局、控件与反馈是否缺失；在实际页面修正后再判断哪些重复说明可以删去。控件标签、必要的状态提示、原因、费用及重要后果保持明确，图标和颜色的含义不靠用户猜测。对照实际运行检查出现位置、点击后果、动态插值、翻译、截断和辅助技术名称。文字、显示或行为变化影响含义时连同关联状态修正；后续视觉和实现新增或改动的文字继续审查，发现、修正与复查保存在当前任务记录。
