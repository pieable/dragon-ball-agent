# 设计参照搜索与原件复用

用于按当前项目发现、匹配和复用视觉参照。用户给出的作品、当前工程与已确认偏好决定搜索方向，本地收藏提供已取得资源的快捷入口。方法保存在 Skill，当前项目采用的风格、参照和源码保存在项目资料。

## 现场发现与匹配

先说明本次要设计的页面、真实内容、使用者、目标平台和开放的视觉问题。用户提供喜欢的作品时，先看实际画面和相关状态，辨认其字体、色彩、形状、图片、密度与动效的组合，并记录喜欢的是整套气质还是具体部分。已有项目明确的视觉决定继续沿用。

方向尚未找到合适参照时，调用 [深度研究](../../deep-research/SKILL.md)。给研究执行者当前用途、代表内容、用户参照、平台条件和未解决的差异，要求带回可查看画面、来源入口、匹配依据及可取得资源。来源发现与核验使用其内置的 [搜索资源表](../../deep-research/references/search-resources.md)。研究执行者沿新发现扩展搜索，前端负责人接收材料后查看关键原画面和来源，按实际效果更新选择。

把用户的模糊描述转成可检索的视觉特征和来源术语，结合中英文表达、相邻题材和不同类型作品查找。题材与风格分别搜索：同一科普主题可以采用不同视觉语言，相近风格也可能来自游戏、教育或生活工具。用户给出的仓库、作品作者、组件库、风格标签和关联项目都可成为后续搜索入口。作品画面从真实站点、作者展示或设计社区取得，可编辑实现沿官方仓库、模板和社区还原追查。搜索中的新差异继续交给 Deep Research 扩展与核验。

对有匹配线索的候选，查看整页、必要的内页、窄屏和交互状态。把观察到的视觉特征与当前真实内容比较，区分外观契合、内容承载和实现适配。借鉴交互表达时，沿一次相关操作观察选择、受影响对象与结果怎样保持联系，核对哪些解释由结构或反馈承担、哪些必要文字仍被保留；只有静态图时，将尚未观察的行为保留为未知。卡片图或首页截图作为发现线索，进入制作的参照继续追到相应页面、组件、主题与素材。候选比较围绕尚未解决的差异展开，用户通过实际画面或可操作样张判断，普通筛选由前端负责人完成。

采用前核对当前来源版本、资源可取得范围、使用条件和目标平台。来源自带设计规范或样式 Skill 时，按本项目需要读取相关内容，具体样式与运行表现一并核对。可直接使用的库沿其正式入口接入；参照来自其他平台时，复用已选视觉关系并在现有工程中实现。文档、源码和实际画面有差异时记录对应版本与差异，以当前要采用的对象为依据。

## 保存与复用范围

搜索期间保留能继续比较和追查的来源链接、必要画面、匹配理由与未决问题。准备采用或需要实际试验的来源，再取得对应源码、主题、图片和字体并固定版本。交付用到的资源随项目保存，以支持继续编辑和重现。因复用、离线查看或入口易失效而保留的样本，记录用途和来源；保存量由这些用途决定。

现有原件库继续作为缓存使用，现场搜索可直接带入新来源。某个项目认可的风格及第三方样式规则保留在该项目，跨项目继续按各自的用途和用户依据选择。

## 已验证资源的索引

本地原件库由接收方以 `DESIGN_RESOURCE_LIBRARY` 绑定路径。绑定后读取库中的总索引；未配置时按上文现场发现与匹配流程查找来源，不假定已有私人收藏。

### 定位实际原件

| 当前需要 | 从库中读取 |
|---|---|
| 完整站点、产品介绍页或营销页 | `sites/*/RESOURCE-RECORD.md`、对应 `source/` 的页面、分区组件、主题与素材；也可查看 `apps/shadcn-dashboard-template/source/vite-version` 的完整 landing |
| 表格、任务、邮件、设置与工作台 | `apps/README.md`，对应应用 `RESOURCE.md`、页面路由、组件、主题和本地数据 |
| 知名网站的布局、图像配置与动画实现 | `replicas/README.md`、对应 `source/`；这些来源的品牌图片和设计用途需保留记录中的具体条件 |
| 标准化控件、状态、字体和色彩变量 | `components/README.md`、`runtime-components.md`，选择当前框架能消费的 shadcn、Material 或 Fluent 源码及主题 |
| 比较成套字体、配色、按钮、卡片与表单 | `brand-previews/awesome-design-md/offline-previews/README.md`，再打开对应品牌的 HTML；同目录资产清单映射本地 CSS、字体二进制、许可与原地址 |

完整页面、控件样本页与品牌还原分别按其实际覆盖使用。需要原站整页时继续搜索原站、完整模板或可编辑项目。按本次未解决的视觉和实现问题追到新来源，并将实际采用的文件、固定版本和素材补入项目资料。

## 从原件进入制作

查看完整画面和必要的内页、窄屏或状态后，读取实现这部分的页面、组件与样式。保留确定采用的字体角色、色彩、留白、图片裁切和交互关系，再用当前真实内容检查整页。用户接受或否决的具体画面作为选择依据，源码能启动与用户喜欢分别记录。

复制组件时同时取得主题变量、工具文件、导入依赖和必要状态。Fluent、Material 源码来自 workspace，取一份 TSX/JS 不构成独立项目；按现有工程使用已发布包，或补齐源码构建所需工作区。图片与字体从真实文件和资产清单取得，按源记录处理不同用途条件。

在现有工程继续使用其框架和组件体系。独立参照从各记录中的正常入口查看，开发服务器停止后用相同目录和命令重启。Windows 的图集深目录可能超过浏览器文件路径长度，使用离线图集记录中的短路径入口或本地 HTTP 入口。

原件源码与适配工程分开保存，修改后检查真实中文、图片、宽窄布局和主要操作。沿用本 Skill 的界面文案审查与运行验收。上游文档用于理解来源，当前用户要求决定本任务采用的内容与方法。
