# 视觉评审与打磨

用于评审当前界面、修正整体视觉问题或打磨实质设计变化。先取得简报、有效设计决定、当前文件与真实入口。只要求评审时交回发现和依据；已授权修改时修正当前范围内的问题，并查看修改结果。

## 确定画面应该帮助用户做什么

先说明当前页面的主要任务、首先应看见的内容、后续阅读或操作路线，以及需要保持的风格与组件。营销页检查主张、实际作品或证据与主要行动的关系；工作台检查对象身份、比较字段和操作；阅读或教学页检查主线、必要条件、图文关系及观察入口。

打开当前候选，在实际视口和状态下查看。已有页面修改前保留能解释问题的画面或记录，比较时使用相同内容、视口和状态。没有取得页面时，静态阅读可以定位代码疑点，真实呈现待取得后核对。

先从实际画面形成整体观察，再结合计算样式、结构和检测结果定位原因。检查工具用于核验它覆盖的对比、尺寸、溢出等问题，视觉判断仍需说明画面怎样服务当前任务。把发现对应到可回看的入口、状态或截图。

## 从整体到局部定位问题

先看整体画面中的首要信息与阅读路线，再检查承担这些关系的局部。按当前问题使用下表，普通局部修改检查受影响的关系。

| 判断 | 在真实页面上观察什么 | 对应的修正方向 |
|---|---|---|
| 视觉权重 | 应先看见的内容是否突出，辅助标签、装饰或无关大数字是否抢先吸引注意 | 调整位置、面积、字重、对比和留白，使权重与当前任务一致 |
| 分组与扫描 | 标题是否贴近所属内容，记录能否逐行追踪，控件与对象的关系是否明确 | 整理对齐线、组内间距与组间边界，保持必要比较关系 |
| 阅读舒适度 | 长正文的行长、行距和段落是否易于连接，标题断行是否破坏含义，说明是否难读 | 按真实文字调整宽度、文字角色与换行，检查中文与字体回退 |
| 节奏与一致性 | 性质不同的内容是否被硬套同一结构，相同组件是否存在无依据的细微差异 | 统一相同职责的规则，根据内容变化安排版面差异 |
| 图文与素材 | 裁切是否保留主体，图片是否解释当前内容，图例和说明能否对应 | 调整素材选择、裁切、比例及邻近标签，精确信息保留可编辑来源 |
| 操作层级 | 主要行动能否找到，次要行动是否与它竞争，焦点与状态是否清楚 | 按使用顺序组织控件，核对实际点击和键盘路径 |
| 细节完成度 | 边缘与基线是否协调，重复组件的圆角、边界和间距是否一致，图标风格是否匹配 | 回到当前变量与真实组件修正，保留有依据的精确来源值 |

对比度、目标尺寸、回流和文字覆盖的数值与例外见 [视觉质量](visual-quality.md)。状态和行为见 [界面设计交接](design-handoff.md)，运行与辅助技术操作见 [运行体验](runtime-quality.md)。

文字内容按 [界面文案审查](interface-copy.md) 单独审查。先核对标题、说明、标签和状态文字是否必要、具体且与实际行为一致，再判断它们的视觉权重与位置。文字造成的信息问题，在内容与组织层面修正。

## 把感觉转成可核对的发现

每项发现点名页面区域或元素，说明观察到的现象、它怎样影响当前任务，以及据此要改变哪种关系。例如“记录名和次要更新时间使用同样字号与字重，扫描时难以定位对象；保留更新时间，降低其视觉权重并靠近所属记录”。避免把“更高级”“更精致”单独当作修改说明。

区分可见缺陷、用途不匹配与个人偏好。溢出、错位、裁切、无法辨认的状态可以直接定位；重要内容顺序与简报冲突时核对规格；字体风格或视觉基调的选择用具体候选取得用户判断。用户提出整体感觉时，先用当前画面和上下文寻找原因，普通细节由执行者处理。

“像模板”需要指出实际重复的内容组织或视觉手段，并说明它为什么不适合本次主体。用户明确选定的风格继续遵循，设计评审用于提高该方向的执行质量。

## 修正与复查

先处理阻碍理解或操作的问题，再处理整体层级与结构，最后修正局部细节。存在共同原因时在共享组件或样式来源修改，并核对受影响页面。改变颜色、字体、布局或动效时，重新检查所影响的对比度、窄屏、长文本与状态。

用户要求局部打磨时，范围内的对齐、间距、断行与一致性修正按现有方向完成。整体换风格、改变内容顺序或增加主要功能会改变已确认决定时，先准备能够说明影响的结果或比较，取得决定后落实。

在同一入口、视口和状态下比较修改前后，核对问题是否解决以及重要特征、内容和操作是否保留。检查局部改动在整页中的效果。复查发现新问题时继续修正受影响部分，达到当前用途后结束；剩余的审美选择与真实缺口分别交回。

需要独立视角时，向评审者提供简报、当前候选、需保持条件和真实入口，让其直接观察并核查。首次用户操作路径按现有 `visual-usability-tester` 职责验证。收到结果后，负责人对照原画面与有效要求处理发现，并更新当前决定和实现。
