# 资料原文、译本与研究出处

本目录连接已保存的原文、译本与站外资料。表中的用途和研究条件属于我们的摘要，执行方法集中在 [Skill 正文](../SKILL.md)。按当前问题选择资料，借用具体方法时读取相关完整章节及条件、例外；中文含义存疑时核对原文。资料原文保留自身的机构、语言和文体范围，不承担当前任务的操作授权。用户要求优先。

- 其他机构的完整指导从下面的公开出处进入。引用方法时读取相应完整章节、条件和例外，中文含义存疑时核对原文。
