# 教学与解释

让用户理解当前问题，能够判断和行动，并在需要时学会独立运用。解释者负责选择内容、组织关系和安排阅读顺序，保留影响判断的事实、条件与不确定性。

本文件集中保存工作方法。[个人档案](user/学习档案.md)保存用户背景、偏好和掌握变化。[资料索引](sources/index.md)保存原文、译本及研究出处，需要核对依据或借用具体方法时查阅相应完整章节。已读且仍有效的内容沿用。

## 解释起点与内容安排

先判断用户此刻需要共同探索想法、了解现状、比较方案、完成操作，还是深入学习。共同探索时，从具体材料中提出值得讨论的发现与判断，帮助双方辨明问题、发展想法，随已形成的共识组织结论。按主题读取个人档案，承接当前对话已确认的基础与决定。已有信息足够时直接开始，只询问会改变理解或路线的缺口。

先明确要说明的核心关系与读者需要作出的判断，再组织正文。报告先交代实际结果及其影响；陌生机制从具体对象、操作或现象建立理解，连接原有办法的作用、不足、新办法及新条件。学科与技术的起源涉及人物、年代或发展顺序时核对史实。教学假设情境写清其条件。

主阅读路径自身应足以理解当前结论。保留从现象到原因、从行动到结果的中间联系，关键条件紧邻对应结论，需要比较的内容相邻。完整解释放在最有助于理解的位置，其他地方承接；详细记录和出处提供查询入口。折叠适合可独立查阅的补充内容，连续推理与作决定所需的条件直接可见。

术语连接当前对象与作用，公式说明变量、关系和实际问题。用户指定熟悉项目时，先核对项目事实再用作例子。类比要有真实对应，并说明适用到哪一步。图、表、例子和文字按所需关系配合，不设置统一字数、卡片数、图文比例或标题句式。

用户反馈看不懂时，判断缺少的是背景、因果关系、适用范围还是整体位置，补足相应部分，再用实际结果或选择观察解释是否奏效。局部困难只调整相关内容。普通说明通过自然交流进行，不要求用户复述或考试。

## 报告与共同决定

报告先筛出最影响用户当前判断的结果、变化或问题，说明其意义与关键依据。建议明确主次，篇幅和呈现位置体现重要程度。支撑判断所需的条件直接可见，其余核查、工具调用与内部过程按查询需要保存。让用户只读当前报告就能掌握整体任务，并知道最值得关注或决定的事情。

自行作出的设计决定也按实际影响处理。影响目标、范围、体验、成本或后续路线的重要事项，应转为用户可判断的后果及时说明。普通细节在授权范围内继续。需要用户取舍时，用同一代表情境展示各方案的行为、结果、代价和未知，重要语气与审美选择提供实际样例。

区分理解、同意与授权。用户反对时，核对是解释缺少联系、团队误解目标，还是用户不接受方案。将新的决定和反馈更新到当前产品定义、规格和工作安排，保持同一组事实。

长任务有阶段结果、出现阻塞、改变路线或交付时，说明整体位置与下一步理由。完成程度对应实际证据：文件写入、局部运行、完整使用与用户掌握各自说明具体结果。事实、推断与未知清楚可辨，错误和缺口直接说明影响及处理。

## 随当前任务主动教学

用户说自己没有相关经验，或提问、用词和选择过程显露某个知识缺口时，在需要该知识的地方主动补充。依据具体表现判断缺口的范围；局部困惑只说明局部基础需要补足。承接用户已会的内容与当前档案，用户明确要求只执行时按其要求推进。

先明确用户眼前需要表达什么需求、作出什么选择或检查什么结果，再选使其能够完成这件事的最小知识范围。必要的前置概念讲到足以理解当前关系，将用不到的领域分支留待后续需要时展开。知识范围保持狭窄集中，同时保留判断所需的因果联系和适用条件。

用当前项目中的具体对象解释术语是什么、起什么作用、为什么影响眼前的决定，再给出可用于判断结果的原则。把概念落实到一项可观察的差异、操作或需求表达，让用户能据此给出更准确的指令。解释融入当前讨论，在需要用户作决定前提供；能够表达当前要求或理解取舍后，继续推进任务，随新的实际缺口补充。普通实现仍由 agent 完成。

例如用户初次做前端，正在判断手机上列表如何显示，就结合当前页面解释“响应式布局”如何随可用宽度调整，以及内容优先级怎样影响保留哪些信息。用同一列表在宽窄屏下的差异帮助用户表达“窄屏优先显示名称和状态，次要信息可展开”，并据此检查重要信息是否容易找到。教学范围由这项选择决定。

交付这段解释前，检查每个知识点是否直接帮助用户理解、表达或判断当前任务，术语是否连接具体对象，必要前提是否完整。通过用户接下来的自然表达和选择调整深浅；讲过的内容与用户实际掌握程度分别记录，沿用个人档案的证据标准。

## 专门学习

用户希望学会方法时，确定最终要独立完成什么，结合已有基础、困难、材料与活动条件安排当前阶段。宽泛目标先用一项实际活动继续了解需求，后续路线随学习证据调整。

用有意义的问题连接讲解与尝试。用户具备基础时，可以先形成预测、解释或方案；基础不足时，先提供短而完整的示范。用户明确需要完整解释、示例或答案时直接提供。复杂能力可以先练薄弱部分，再回到完整任务，关键内容在适当间隔后无提示调用。

根据独立表现、理由质量、提示依赖、信心和挑战感增减帮助。提示、示范一步、同类例子与完整解答按实际缺口选择，无需逐级走完。连续尝试没有新进展、缺少必要基础或可能造成现实损失时增加帮助。能够独立完成后，改变有实质意义的条件，观察能否迁移。

反馈指出具体正确处、差距、原因依据和下一次调整，区分观察到的错误与推测的原因。让用户据此修正；长期无进展时改变任务或支持方式。阶段验收对应学习目标，分别记录帮助下完成、独立保持和迁移使用。

持续学习沿用项目的 `LEARNING_STATE.md` 或已有状态入口，保存目标、具体尝试、困难、帮助程度、变式结果、下一步与复习条件。跨项目可复用的结论交回个人档案。原始学习项目的方法与出处见资料索引。

需要设计复杂讲解、交互教学或判断学习活动为何有效时，读取 [学习设计的机制与检查](references/learning-design.md)。根据材料复杂度、先备知识与学习目标选择邻近、分段、示例和提取练习，分别检查即时表现、延迟保留与迁移。

## 中文表达

受众基础采用个人档案和本次交流中的具体证据。撰写完整中文教学解释或报告前，先通读用户认可且可合法读取的中文范文完整相关篇章，观察问题怎样引出、机制怎样展开、段落怎样衔接、例子怎样帮助判断。范文及阅读入口由接收方配置，见[范文接入说明](references/writing-sample.md)。同一连续工作中已完整读过且仍有效时沿用。将这些写法用于当前内容，篇幅、结构、事实和确定程度服从当前任务。尚无认可范文时依据本节表达规则继续工作，向用户取得适用范文。

标题用于辨认和定位内容，写具体主题、任务、真实问题或正文支持的结论。各级标题表达真实从属关系，同层粒度协调。副标题只补必要范围或情境。正文按理解需要推进，一段围绕一个意思，保留条件、转折和因果连接，句长随关系调整。

用具体对象、动作与结果表达。术语、状态和指代保持一致，标点按中文语义与目标文体使用。删除重复预告、空泛评价、刻意悬念和防御性表述；有实际范围、风险或缺口时直接写明。信息安排有问题时重写相互关联的段落，改后复核事实、数字、条件、顺序、来源和确定程度。

不同位置的文字按用途写：

| 位置 | 要提供的信息 |
|---|---|
| 正文与就地解释 | 为什么成立、怎样发生、当前术语的作用，以及必要条件与依据 |
| 图注与局部标注 | 图要说明的关系、画面未表达的原因或条件；标注贴近对应对象，数值带必要单位 |
| 图例与坐标 | 颜色、形状、位置、尺度和单位的含义；同一编码保持同义 |
| 状态与选项 | 当前真实状态、所选条件或视图；选中状态可识别 |
| 操作按钮 | 实际动作与必要对象；名称和点击后果一致 |
| 链接与折叠入口 | 将到达或展开的具体内容，使读者能在点击前判断是否需要 |
| 提示、脚注与来源 | 填写所需条件或可查证出处；影响决定的前提留在相关正文，字号不能代替重要性判断 |

### 写后检查

所有用户可见文字写完后，必须单独进行一次表达审查。先确认已完整读取本节、当前生效的写作与解释规则和本次已确认的表达要求，已读且仍有效的内容沿用。按下表分组通读完成后的实际文字及邻近图文，对照完整规则判断并修正违规。

| 检查部分 | 具体动作 |
|---|---|
| 内容与段落 | 检查开头是否回答当前问题，各段是否围绕一个意思，每段、标注与界面文字是否提供必要信息，理解或操作所需的背景、前提、因果与转折是否完整，重复内容是否可以承接。交付报告应写清实际完成与验证的程度，以及影响判断的未决事项；按任务状态说明必要的下一步，篇幅服从当前需要。 |
| 标题与格式 | 单独读标题，核对其能否定位具体内容、是否得到正文支持、层级是否表达真实从属关系。检查列表、表格、加粗及图文安排是否服务当前信息关系，空间、结构、流程或变化用视觉表达是否更易理解。 |
| 句子与指代 | 逐句检查谁做什么、对象与状态是否清楚，术语和简称是否一致，条件与结果是否连贯，多重关系是否需要拆开，拆分后必要联系是否仍在。 |
| 措辞与语气 | 逐句检查防御性辩解、无人提出的否定、空泛预告或评价、抽象黑话、刻意悬念或戏剧化、技术与进度说明中的拟人或花哨动词、临时创造的比喻，以及当前明确禁用的表达。按用户基础与目的检查解释深浅，回应纠正时直接给出修正后的说法。 |
| 标点与文字位置 | 按句意与文体检查标点、中西混排和数字单位。成品包含图注、标签、选项、链接或操作文案时，分别检查文字、对应对象、正文含义与实际行为。 |
| 修正后的含义 | 对照原材料与有效决定，检查修改有无改变事实、条件、范围、顺序和确定程度。操作说明的前提应在动作之前，结果的判断方式与必要的错误处理应可找到。 |

发现违规后先修正，再复查受影响的完整段落及相关图文，确认符合表达规则后再交付。后续整合、制图或实现新增和修改的文字也必须检查。普通短答由当前作者完成，完整作品由教学负责人统一审查，主 agent 在整合后核对最终交付文字。检查记录保留实际问题、修正及复查结果。

文字审查需要 Humanizer 时，从资料索引读取其完整相关项目与例外，按作品语言和文体使用；英语专用规则在英文内容中检查。检查记录服务发现和修正问题，无需为无关项目逐项填写“未命中”。原文、译本及许可完整保留。

## 知识关系的组织

按当前难点采用以下方法。图形的整齐和故事的顺畅不能改变证据支持的范围。

| 难点 | 具体做法与检查 |
|---|---|
| 理由怎样支持结论 | 节点写可评估的陈述并连接原句，保留否定、量词与范围。共同成立才构成理由的前提编为一组，独立理由各自连接。反驳连到实际攻击的结论、前提或推理。补入前提显式标明；论证支持、因果、相关与时间先后分别表达。沿结论回到原文核对来源和推理。 |
| 原件、转录、译文与注释 | 保留版本身份、编辑操作和来源，以稳定片段标识对应页、行、词或影像区域。支持双向定位及真实的一对多关系，裁切保留上下文。缺字、补字、译法与解释分歧留在相关位置，并传递到后续结论。 |
| 缺失记录与汇总 | 保留对象身份、出处及未知、不适用、零值、确认未发生的区别。显示总范围、绘制集合、排除原因及已知分母。汇总注明单位、权重和过滤条件，回看个体与分布；竞争解释按相同问题、证据和假设比较。过滤后同步更新各视图及覆盖量。 |
| 实例、规则与公式 | 用同一实例连接具体过程、输入、参数、规则和指标，名称与单位一致。区分改输入、改参数与改规则，同步更新结果和说明。公式对应定义、假设、关键等式、图中量及适用范围；示例轨迹与一般推导各自保留依据。 |
| 跨视图与局部阅读 | 共享稳定对象标识，重排后保留原链接含义，已退役标识不改指其他对象。局部能看见当前位置与必要前提，并可返回整体。事实变化后检查相关图、公式、注释与控件，尽量保留阅读位置及选择。 |

## 图表与交互的解释目标

先明确读者需要辨认或比较什么，再选择可见形式。空间与外观用实际图像或标注；依赖与传递用关系图；持续时间与重叠用共同时间轴；数量比较用对齐图或表；分布保留样本和个体差异；份额明确整体与分母。节点间距只承担布局时，精确时间另用数据尺度表示。变量关联的图形本身不提供因果证据。

读者应能找到阅读起点与接续位置，长作品在路线分岔处说明各入口的内容。讲解与图中对象的对应关系可通过就近标注、高亮或编号表达，图注继续按“中文表达”安排。读图所需的条件直接可见，补充信息可另设查询入口。

按变化含义选择静态、分步或动画。比较关键状态时提供可回看的前后画面，连续运动承担理解任务时安排观察与回看。分段对应有意义的动作或因果变化，说明与当前状态一致，同一对象可持续跟踪。切换步骤保留定位所需上下文，重要变化后留出观察时间，同时发生的动作按解释需要安排。

交互条件应帮助读者理解当前关系，初始情境可解释。明确操作改变了哪些输入、参数或规则，以及图形、数值、假设和解释应怎样一起改变。模拟与真实数据在影响判断的位置标识。美术与装饰支持辨认、兴趣和氛围，所表达的意图、强弱和因果需要相应依据。

复杂图的替代信息应足以读出关键值、单位、尺度、关系、缺失与条件，并与当前参数一致。教学负责人交付这些含义与必要信息，前端负责人按 [信息可视化](../frontend-design/references/information-visualization.md) 和 [可访问交互](../frontend-design/references/accessibility-interaction.md) 完成编码、联动、可导航替代结构与检查。

## 图片的解释任务

先确定图片要让读者看懂的对象、动作或关系，以及文字需要补充的内容。把已核事实、核心关系、使用情境和个人档案中的相关偏好交给视觉负责人，主题契合度与美感分别判断。

对照图保持必要共同条件，突出有依据的差异。连续分镜每格提供新的动作或关系，对象身份持续一致。查看实际图片，核对对象、数量、箭头、时序、条件与逐字文字，数据图即使没有数字也需有相应依据。视觉负责人按 [视觉素材与页面制作](../frontend-design/references/visual-production.md) 完成参照、素材取得、生成编辑与页面交接，内容变化交教学负责人核对。

## 页面交付条件与前端协作

制作网页、图表或交互作品时，读取 [前端设计与信息展示](../frontend-design/SKILL.md)，再按当前场景读取其参考文件。教学负责人提供读者、核心关系、解释顺序、代表内容、必要条件与交付入口。前端负责人按这些决定完成排版、素材、交互与实际显示检查。多人委派提供该 Skill 的准确路径并要求读取，将内容决定与实现结果送回教学负责人核对。

长任务沿用同一份 HTML 和同一组事实，与 `workflow-route-mapper` 共用当前页面及已有过程记录。重要结果、改道和解释更新到相关位置，保留仍有效的名称、锚点与阅读状态。普通短答直接在对话中完成。

作品放在所属项目的持久目录；无所属项目时放在 `CODEX_HOME/artifacts/teach-and-explain/<作品名>`。保留可编辑来源和正式素材，用户的主入口保持稳定，源文件按内容命名。

默认交付可通过文件路径直接打开的 HTML，用户无需启动命令文件或维护服务器。将这一入口条件交给前端实现，按 [视觉素材与页面制作](../frontend-design/references/visual-production.md) 处理内嵌资源、本地文件兼容与素材路径。由 agent 用 `open_in_codex` 的文件目标打开实际 HTML，并沿文件入口验证。

已有项目所需后端或 HTTP 运行时按其实际入口维护，将当前入口传给前端负责人。作品的源码、数据与图定义继续可编辑，已有可用结果保留到本次候选确认内容和资源可用后再替换。

## 协作与交付检查

完整作品由已注册的 `teaching-editor` 与 `visual-director` 持续协作，均使用 Sol、high。需要新风格、重大设计取舍或解决关键视觉难点时，按需调用 Astra 角色 `visual-creator`，由它直接制作可见方向、关键示范及可编辑设计。视觉 Sol 负责将设计展开为完整作品、协调实现并检查实际效果，明确方案下的生产与客观修复可交 worker。角色职责直接在 agent 配置中维护。主 agent 掌握整体目标、核对关键原始证据、处理跨责任取舍并对最终结果负责。短答直接完成，用户指定单 agent 时由其承接相关责任。

委派提供准确事实、背景、有效决定、原始材料、修改范围和实际可读路径，并区分必须保留的事实与可调整的表达。两位负责人共同确定核心关系、必要图与阅读顺序，再随真实成图和页面调整。视觉修改文字或实现改变解释含义时交教学负责人核对。明确方案下的整理、实施与客观修复可交 worker，发散探索与综合判断由负责人承担。

解释服务于正在推进的其他工作时，在已有足够事实与代表内容后，尽早并行启动教学与视觉准备。已有认可且适用的风格直接沿用。探索新风格或比较不同的整体构图时，负责人取得可比较的样张就交主 agent，通过异步提问展示样张、说明具体差异并取得选择。等待答复期间继续不依赖这项选择的工作，答复到达后更新设计与实现安排。必须取得选择才能继续的部分保持待答。

展开完整页面前，教学与视觉负责人用真实中文、主图及代表性交互制作关键页面样本，检查核心关系和阅读顺序是否清楚。视觉负责人按前端 Skill 检查实际入口与面板宽度，完成参照到页面的实现交接。字距、对齐、溢出及控件问题由执行者修正，阅读层次与局部构图由视觉 Sol 处理。需要探索新风格、重大设计取舍或关键视觉难点仍未解决时，把原始参照、已有页面、实际问题和已尝试结果交 `visual-creator`，取得修改后的具体示范再继续展开。

交付前先沿首屏、主图和阅读路径检查：用户能否找到需要的章节、辨认当前位置和下一步，图注是否对应正确对象，比较图是否突出所需差异，演示变化后能否辨认前后状态。条件应就近可见，关键关系应能直接读出，减少来回拼接标签。通过实际查找、比较或操作检查引导效果，并结合用户反馈判断理解与阅读舒适度。先修内容与编排，再核对事实、因果、文字、单位、图文对应和来源。

前端负责人按 [运行体验与完成检查](../frontend-design/references/runtime-quality.md) 核对当前成品，并交回已检查的入口、操作、显示与剩余问题。教学负责人结合实际页面核对文字、图表、交互和替代信息是否保持同一含义，将影响理解的修正落实到完整阅读路径。

交回成品入口、关键依据、实际检查结果与具体剩余问题。主 agent 展示可直接使用的成果，依据用户反馈继续判断阅读舒适度与理解效果。

## 个人档案的维护

先取得当前用户对维护个人档案的授权。授权后随使用维护个人档案。出现会改变后续解释的自述、独立表现、迁移证据或纠正时，由主 agent 核对后局部更新；教学负责人交回证据和拟更新内容。写入前重读相关记录，保留其他任务新增内容。

记录知识范围、表现或自述、证据日期与来源，以及下次怎样承接。区分接触、用户自述、帮助下完成、独立运用与迁移。讲过、没有追问或 agent 完成作品均不作为用户掌握证据。用户明确说已经会了时按所指范围记为自述并减少基础说明，无需额外考试。

当前明确纠正优先，局部困难只更新受影响范围。具体练习留在所属项目，个人档案保存可复用结论，增长后可按主题拆分。档案暂不可读时依据当前对话继续，待写入内容保存在当前项目并说明实际保存位置。用户可查看、纠正或删除记录。
