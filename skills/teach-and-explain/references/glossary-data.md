# 词汇表数据与维护

项目根目录默认使用 `词汇表.html`。初次创建时复制空模板；已有文件应直接更新，保留其布局、样式、交互和已有词条。

## 唯一数据入口

词条的主要来源是 HTML 内唯一的区块：

```html
<script type="application/json" id="glossary-data">
{"project":"项目名称","updated":"2026-10-25","entries":[]}
</script>
```

AI 先读取这个区块，再理解和合并变化。固定模板按词语、英文、别名、领域、小组、释义、实例、说法与语境、区别、关联说明和来源标题做本地文字匹配，支持空格分隔的多个词；每个查询词都须命中至少一个字段。ID 和来源 URL 不参与搜索，网页不连接 AI。旧模板搜索范围可能较窄，改版时核对实际页面。

## 字段

| 字段 | 类型与含义 |
| --- | --- |
| `project` | 字符串，项目显示名称 |
| `updated` | 字符串，更新时间；建议 `YYYY-MM-DD`，未知可留空 |
| `entries` | 词条数组，可为空；领域及主题按首次出现顺序组织，同组词条保持数组顺序 |
| `id` | 必填非空字符串，唯一且稳定；改名称时保留 ID |
| `term` | 必填非空字符串，词语名称 |
| `domain` | 必填非空字符串，领域名称；筛选项由实际数据生成 |
| `group` | 可选字符串，领域下的主题小组；缺省时直接归入领域，旧数据保持可用 |
| `meaning` | 必填非空字符串，供整体扫读的准确、通俗关键释义 |
| `english` | 可选字符串，必要时提供英文名称 |
| `aliases` | 可选字符串数组，当前语境中成立的别名 |
| `example` | 可选字符串，当前项目的具体实例 |
| `phrases` | 可选数组，每项为 `{ "text": "通俗表达", "context": "当时语境" }` |
| `distinction` | 可选字符串，与容易混淆概念的区别及成立条件 |
| `related` | 可选数组，每项为 `{ "id": "目标ID", "note": "关系说明" }`；目标必须存在，说明可留空 |
| `sources` | 可选数组，每项为 `{ "label": "来源名称", "url": "https://…" }`；只允许完整 HTTP/HTTPS 链接 |

没有内容的可选字段直接省略。`phrases` 中的文字保留当时语境；转述应按转述写，不伪造逐字引语，不自动转成跨项目的永久同义词。项目约定用语应说明本项目中的含义，不能包装成通用标准。来源对应当前解释的具体主张。

## 更新已有文件

1. 读取当前 HTML 中的完整数据，核对正在讨论的概念与实际项目资料。
2. 在现有 `entries` 上合并增补或修正，保留未受影响的词条和字段。不要用“本次新增的词条”替换整个数组。合并概念或删除词条时，先检查所有关联并同步修改。
3. 保存合并后的完整 JSON 到临时文件，更新 `updated`。写入前核对 HTML 未被其他执行者修改；若有变化，重新读取和合并。
4. 运行更新器（路径按安装位置调整）：

   ```text
   python scripts/update_glossary.py "词汇表.html" merged.json
   ```

   更新器只替换 `glossary-data` 的内容，保留其余 HTML 字节。它先检查全部字段类型、重复键、唯一 ID、关联目标、来源链接和唯一目标区块，再在同目录写临时文件并原子替换。校验失败会报告原因并保持原文件不变。它不负责概念合并或判断含义是否准确。

5. 重新读取实际 HTML，确认词条总数、未受影响的词条、改动和关联；从文件路径打开，检查修改词条的显示、查找和关联跳转。删除临时 JSON，避免留下第二份待维护的数据。

直接编辑 HTML 时仍须满足同一协议；JSON 中的 `<`、`>`、`&` 和 U+2028/U+2029 应转为 Unicode 转义，避免 `</script>` 提前结束数据区块。优先使用更新器完成转义和校验。

## 页面与模板

模板自包含，不依赖网络、外部字体或数据文件；必要图像随 HTML 内嵌。空模板不含任何项目实例。项目名称、词条和更新日期由嵌入数据生成；标题“词汇表”、样式和交互保存在同一 HTML 中。领域与可选小组形成连续浏览的分类，词头和关键释义默认可读，其余字段按需展开。

词条更新通常只改 JSON。只有已经确认需要改变页面功能或设计时，才改其 CSS/JavaScript。交付前核对桌面与窄屏、空结果恢复、关联跳转与键盘焦点；新词较长或字段结构变化时，复查相应显示。
