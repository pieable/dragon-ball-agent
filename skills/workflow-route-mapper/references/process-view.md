# 分层展示 AI 工作过程

用于过程不断增长、单图难以连续阅读，或用户要审视 AI 的行动与选择依据时。先沿用任务已有页面和记录，以当前结果为入口，再提供阶段查找与材料回查。当前事实由任务负责人核对，页面展示已写入的记录。

## 选择阅读范围

当前摘要先说明目标、当前动作、取得的结果、尚缺什么、谁需要行动与下一步，内容更新时间反映事实或说明的实际改变。用户正在作决定时，对应的理由、代价和条件直接可见。

过程按实际工作阶段和已有计划编号组织。阶段名称说明在解决什么，摘要保留主要结果、改变方向的重要依据和未决事项。选择阶段后，显示该阶段的可读记录；历史较多时，可按编号、对象或问题检索。筛选改变查看范围，原记录和可回查入口继续保留。内容较少且需要连贯阅读全文时，直接用连续正文。

一个行动轮的记录连接本轮问题、必要的行动概述、所得结果和下一步判断。普通操作合并到它服务的工作中，相关工具输入输出或长日志供需要时查询。出现独立候选、改变判断的证据或路线状态时，保留相应记录及来源。轮次按任务已采用的定义接续，不随每次工具调用增长。

归属、先后和判断关系分别表达：阶段目录说明记录属于哪里；顺序说明发生先后；“支持、反证、调整、替代、吸收”说明依据或路线关系。并行行动按实际关系呈现。采用局部关系图时继续使用 [路线图语义](route-graph.md)，放弃核心的候选从共同判断点分叉，局部吸收写清吸收内容。

## 记录重要选择与依据

选择记录写明当时的问题和条件、实际比较过的选项、采用或放弃的做法、理由及其影响，附决定性材料或验证入口。阶段摘要让重要变化可发现，进入记录后能直接读到原因和结果。旧选择后来被替代时，保留当时依据并链接新决定。

验证结果与路线是否仍采用分别写。例如一种调用办法曾验证成功，后来因使用成本而放弃，保留“验证成功”和“已放弃”两项事实。已安排的动作、实际执行和经过检查的结果按取得的证据记录。无法从现有材料恢复的历史标明具体缺项。

为要回查的阶段、轮次、选择和材料保留稳定标识及名称。改标题或重排时，原入口仍定位同一对象；证据摘要说明它支持哪个结果、覆盖哪些条件。公开来源链接到具体页面；本地原件采用当前展示入口确实能提供的文件、同页原文或材料定位。只有路径时保留准确路径和相关内容摘要，实际入口可用后再提供跳转。核对服务的可提供范围，来源多不意味着服务会自动开放这些文件。

教学解释放在用户需要理解的决定与成果旁：说明陌生概念在当前问题中负责什么、为什么有此结果、条件改变会怎样。解释与过程引用同一项有效结果及其依据。无需为了记录而重复已经说清的内容。

## 制作与持续更新

优先复用已有 HTML 的目录、展开、链接和数据读取。没有已有页面而需要持续进度时，可复制本 Skill 的面板资产，按 [运行与数据](sidebar-panel.md) 使用阶段记录。它提供当前状态与过程查找；需要更丰富的教学编排时，沿已有任务页实现对应内容。

任务负责人接收并核对委派结果后，更新受影响的过程记录和当前摘要。取得证据、改变选择、进入阶段或结束时核对目标、状态、结果、待决定和下一步作为同一组是否一致。普通未改变内容的轮询沿用原更新时间。记录写入和页面读取分别核查，完成时说明实际结果与剩余问题。

更新页面时保留可继续使用的定位、阶段选择、当前焦点与阅读位置。用户主动导航时进入所选记录，普通内容刷新沿用正在阅读的位置。原记录发生纠正时，当前正文采用已核对内容；会改变后续理解的旧判断、纠正原因与新依据继续可回查。使用独立 JSON 或 Markdown 时保留其可编辑来源，显示层与来源共用记录，不人工维护相互竞争的副本。

内容较多时按实际信息层次选择导航；树用于多层归属，选择列表用于阶段定位，连续列表用于按顺序阅读。依据详情可以展开，理解当前选择必需的理由和条件保持在相关记录中。折叠内容随页面滚动，窄屏重新安排比较和定位，避免把长图缩成难读的小图。

## 验收与复用

沿实际入口检查当前摘要；从一个阶段进入重要选择，再到支持它的材料，核对对象与条件；查找放弃路线及原因；筛选、清除和原链接仍能返回相应记录。新增记录后，当前状态与摘要、内容时间和正文一致，已有选择和定位保持可用。

检查实际侧栏及窄屏的浅深色、键盘和代表性交互。长历史使用有明确性质的压力材料检查查找与显示；该材料留在验证记录中，生产内容继续使用真实过程。增长成本由当前实际数量和读者需要判断，不给过程记录设置任意删减上限。

本机试作位于 `artifacts/teach-and-explain/skill-self-review`，从 Skill 根目录的 `../..` 定位本机根目录。其教学介绍与过程样本共用入口，原文在同页可查。复用时读取当前作品的来源和交接记录，借用实际查找与证据展示机制，改成新任务的事实。

## 制作依据

- [LangSmith 的过程与执行记录](https://docs.langchain.com/langsmith/observability-concepts)：同一组记录提供可读过程和完整执行树。此处借用同源分层的机制，任务轮次与哪些证据改变判断由负责人核对。
- [Carbon 的折叠指导](https://www.carbondesignsystem.com/building-blocks/core/components/accordion/guidelines)：按需内容可以折叠，需全文阅读的内容保持连续；多层归属可采用树，重要信息的可发现性另行检查。
- [Microsoft 的决策记录](https://learn.microsoft.com/en-us/azure/well-architected/architect-role/architecture-decision-record)：保留问题、选项、选择、后果与状态，改变决定时关联旧记录。这是架构文档实践，此处借用选择理由及演变的保存方法。

这些来源提供制作参照；本 Skill 的过程选择、教学联动和原生页面组合在具体作品中检查。依据核验日期为 2026-10-10。
