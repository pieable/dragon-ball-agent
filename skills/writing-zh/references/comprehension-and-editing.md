# 编辑诊断与实例

用于处理实际作品的阅读障碍。先找读者在哪里停住、猜测、回读或自行整理，再决定修改范围。以下方法是编辑工具，按困难调用。

| 读者的困难 | 编辑判断与动作 |
|---|---|
| 不知道哪些内容与自己有关 | 核对读者、用途与主线；删移工作过程，保留会改变理解、选择或操作的信息 |
| 读完几处才知道一件事的状态 | 围绕同一问题重组目标、现状与缺口；详细证据另设入口 |
| 事实或机制依据不足，无法解释为什么发生 | 回查决定含义的原始材料、对象、条件与因果；需要时继续调查。尚未查明的部分保留证据缺口及影响，不用流畅的改写补造事实或机制 |
| 每段都懂，整体没有前进 | 做反向提纲：写出各部分实际贡献，合并重复，补上推理缺环或重排依赖 |
| 句子很短，仍不知道怎样发生 | 展开参与者、动作、条件与后果；稳定对象，用同一实例连接机制 |
| 必须记住上一段才能比较 | 按相同维度并列呈现；给数据就地标明指标、单位与时点 |
| 图看过了，关系还得从长文拼 | 明确图要回答的问题，让位置、连线、分组或变化表达对应关系；标明必要图例与条件 |
| 标题醒目，关键限制却看不到 | 把限制放到决定结论成立的位置，调整主次；标题概括真实内容 |
| 主线混着大量提醒和自证 | 保留具体未知及影响；合并共用条件，将核验过程转为查阅材料 |

## 从真实问题形成编辑动作

以下是取自项目报告问题的改写示意，供识别方法，实际状态应按本次材料核实。

**把状态放回同一问题。** 目标页写“内部原话不自动公开”，后面才说能力未落实，折叠处又说仍采集工作区。可将相关信息合并为：

> 公开内容控制尚未完成。目标是让妹妹选择适合节目的内容转述；当前画面仍采集工作区，字幕发布控制也尚未按这一区别落实。

这里保留了期望、实际行为与差距；具体接口和验证记录可从同处查阅。

**让比较直接可见。** 多个模型的速度、误差率和资源要求连写成几句话，会迫使读者记住指标顺序。把模型作为行、指标作为列，在表头给单位和测量条件；正文说明对当前选择有意义的差异。不同测试条件的数据先说明可比范围。

**用机制承载术语。** “OCR：识别文字”只是释义；补上“画面里的字 → 识别出的原文 → 翻译”，再说明原文漏读会怎样影响译文，读者便能理解它在系统中的位置与作用。

## 检查方法的适用范围

反向提纲检查已有内容的作用与次序；已知到新知的推进减少概念跳跃；段落统一性使一个局部足以回答相应问题；就地对照减少读者凭记忆拼接信息。充分展开与简洁共同服务理解，字数、术语数量或图表数量都不能独立判定质量。

读者需要连续论证或叙事时，检查前后铺垫、论据和节奏；查阅型材料检查定位与局部完整性；操作指南沿真实动作检查前提与后果。不要把报告的扫读安排推广为所有体裁的固定结构。

内部检查可用具体定位、比较或解释问题检验作品是否提供了答案。真实用户反馈用于修正对其理解困难的判断；不要求用户每次参加测验，也不把模型自查写成真实读者已理解。
