# 中文写作与编辑

交付读者能够理解和使用的作品。作者负责筛选材料、建立关系和解释意义，让读者把精力用于判断内容。把模型已有的写作与编辑能力用于当前情境，方法随体裁、材料和读者调整。

## 部署材料

本 Skill 的公共主干与个人材料分开安装。涉及本地样例、档案或维护历史前，读取 [本地依赖](LOCAL-DEPENDENCIES.md)；缺失材料不等同于方法已执行。

## 确定这份作品要带来什么

从任务与上下文辨明读者是谁、已经知道什么、关心什么，以及读后需要理解、决定、操作或体验什么。判断作品会怎样被阅读：连续读、扫读选读、查找局部，或边操作边读。这些判断影响取舍和写法，通常由作者完成；缺失的信息会改变目的或重要取舍时再询问。

面向用户的报告采用平等、自然的成人交流语气。用户需要掌握目标与边界、方案与关键机制、实际结果与验证程度；按当前问题选择要讲的部分。正文按当前用户确认的阅读偏好组织；当用户不愿阅读满篇文字时，复杂内容应让图示、对照或交互承担必要解释，不能只把文字移进方框或折叠区。

所有文档先确定读者，遵循全局 HTML 与 MD 双视图分工：面向用户的 HTML 用直观关系、对照、情境或交互组织实质信息，按人的理解需要重新组织，文字补足必要解释；面向 AI 执行和接续的 MD 按检索和正确接续组织，使用清楚标题、稳定编号、相关术语和精确文件引用，不套用面向用户的篇幅压缩标准。两者共用事实、对象标识和主要来源并能互相定位。后文关于扫读、主次和正文取舍的要求按实际读者运用。

独立作品补足离开会话仍能理解的背景；报道、教学、操作指南和文学作品按各自用途组织。

## 组织内容，再展开表达

从材料中找出读者真正需要回答的问题，决定各部分的作用与关系。复杂作品先用真实内容形成提纲或图文草稿，检查能否承载主要结论、关键依据和必要背景；写作中出现缺口就调整结构。栏目数量、篇幅和媒介服从内容。

将回答同一问题所需的信息放在一起。例如判断某功能是否可用，应能在相应位置对照目标、当前行为和重要缺口。共用背景集中解释，局部入口补足辨认对象与条件所需的信息，详细记录提供准确入口。

依据读者要作的判断确定正文的颗粒度，把材料分配到主线、就地解释或查阅资料。接口定位、逐项检查和文件数量等细节，影响当前理解或决定时才展开。完整性由正文与可查阅材料共同承担，正文保留足以独立理解的主线、关键依据和重要缺口。原材料再丰富，也要完成取舍，不能以逐项搬入正文作为完整交付。

安排信息推进：每部分完成一个可辨认的表达任务，后文在前文基础上补充、解释、比较或发展。重复应服务于导航、必要回顾或局部独立理解；已有结论换句话再讲而没有新增作用时，合并或删除。材料中的发现顺序、修复经过与核验记录，按读者用途重新组织。

选择能直接表达关系的形式：并列差异适合对照，组成与依赖适合关系图，时序和状态变化适合流程或时间轴，机制解释适合连续实例。让文字、图和交互共同完成解释，避免同一内容多处完整复述。报告支持扫读与跳入局部；连续论证、叙事和实际操作保留必要顺序。

## 写清关系，形成主次

从读者熟悉或刚建立的对象引入新信息，交代参与者、动作、条件和后果。术语应帮助准确表达，陌生机制用具体情境连接；简洁时保留关键因果、例子和连接词。句子中的对象或逻辑层次过多，就重新组织，避免用名词串和缩写把理解成本转交读者。

标题直接呈现具体内容、问题或正文支持的结论，帮助读者定位和区分。报告与说明页面不用“先看……”“接下来了解……”等带读式标题；操作标题直接写真实动作。突出程度与信息重要性一致，会改变判断的条件靠近相应结论，不能藏在小字、图外远处或折叠内容里。已有布局与名称足以表达时，省去多余的副标题和说明。

直接说结果、理由、影响和具体未知。结论的适用范围说清一次，并在需要的局部保留足够提示；删去无新增信息的辩解、无人提出的否定、空泛评价和工作量展示。事实、来源主张和作者判断可辨认，语气的确定程度与依据一致。文学表达和有解释作用的类比按作品需要使用。

## 从读者位置编辑成品

初稿完成后，重新检查实际作品，允许成组重排、合并、删除或补写。先解决内容缺口和组织问题，再处理句子与排版；局部润色不能代替结构修订。已有草稿可用反向提纲核对每部分实际贡献。

按作品的阅读方式检查：扫标题和主图能否定位；从关键区块进入能否理解对象、结论与条件；需要比较时能否就地看出差异；连续阅读时是否有推进、是否缺关键连接。检查者依据作品取得答案，避免用作者脑中的上下文替作品补全。具体困难可查[编辑诊断与实例](references/comprehension-and-editing.md)。

改写后对照原材料核对事实、数字、范围、时点、条件、顺序、来源和确定程度，核实删去的信息确实不影响当前理解与判断。报告概括已完成结果、实际验证程度和重要遗留；详细依据保持可追溯。细致措辞检查见[表达与保真](references/expression-and-review.md)。

HTML 等作品在实际页面上核对文字、图示、折叠和动态状态，不能仅以源码或纯文本通过代替。界面文案按[界面中的文字](references/interface-copy.md)处理，显示与交互结合 [frontend-design](../frontend-design/SKILL.md) 验证；解释与学习设计结合 [teach-and-explain](../teach-and-explain/SKILL.md)（同一任务已读且仍有效时沿用）。后续整合新增的内容同样检查。短答直接自查，复杂作品按实际风险安排独立检查，主 agent 对最终交付负责。

## 需要参照时调用范文

遇到具体的结构、语气或表达困难，或用户要求仿写时，从[样例索引](samples/index.md)选择相同表达任务的作品；库中不足再查找成熟实践。读相关段落及足够上下文，借鉴整篇组织时读全文。采用其有效方法，事实与结论仍来自当前材料。重要文风或仿写程度尚不明确且会影响全文时，先按[短样校准方法](references/expression-and-review.md#采用适合双方关系的语气)用本次内容核对效果。范文供专业判断使用，不默认大量阅读或套用固定文风。
