# 经营资料分析方法

用于从经营数据、公司披露和交易记录判断一条产品线的商业进展。先选会改变当前判断的少数主张和指标，再沿着资料追到它们实际代表的客户行为、交付结果或经济贡献。数据粒度服从可获得的材料；初筛不扩大成完整财务尽调。

## 从商业主张找到可观察的事件

把公司说法改写成可以由经营记录检验的问题。例如，“客户接受度高”要落实为同一批客户是否付费、续约、复购或增加用量；“订单快速增长”要区分新签合同、已排产订单、发货、验收、收入确认和回款分别增加了多少。先确定对应的产品线、客户群、记录期间和关键事件，再读取最接近这些事件的合同、续约或取消记录、订单、发票、发货与验收数据、使用记录或财务披露。

检查经营指标的分子和分母分别是什么、按什么时间点计算、包含哪些客户和产品、是否使用年化或估算值，以及定义是否随期间改变。能取得原始明细时按同一口径重建指标，并与公司披露或财务报表核对；有差异时查找范围、时间和定义的原因。合同额、订单额、交易额、确认收入、应收款和已收现金反映销售到回款的不同阶段，按当前问题查看相关环节，不把它们合称为“收入”。合同与交付条款影响收入确认时间时，结合财报中相应的会计政策和披露判断。

## 按交易机制重建变化

使用与产品线收入机制相符的分解式。下面这些方法只在对应的商业模式下成立。

- **能够合理定义 ARR 的订阅业务：** 先按公司披露确定 ARR 计算的合同范围和年化方法，并把 ARR 作为经营指标，与当期会计确认收入区分开。重建公司整体 ARR 桥接：`期末 ARR = 期初 ARR + 新客户 ARR + 原客户扩容 - 原客户缩减 - 原客户流失 ± 范围调整`。另按期初确定的固定客户群计算净收入留存率（NRR）：`期末同一客户群 ARR ÷ 期初同一客户群 ARR`，排除新客户；毛收入留存率（GRR）在同一客户群中进一步排除扩容，反映缩减和流失后的保留金额。调价、产品扩容、汇率、并购及其他范围变化如何归入 NRR 或 GRR，按公司披露的计算定义处理。记录客户群进入条件和测量期间，才能区分整体增长来自新客户、原客户变化还是范围调整，并判断收入基底是否稳定。
- **按件、按次或消费品交易：** 从实际售出或交付量和扣除折让、退货后的实现单价重建收入。解释数量、价格和产品组合如何推动变化，采用能与实际收入变动对平的分解口径，并说明实现单价是否合并产品组合；有可靠数据时再拆分渠道库存、促销、退货或外汇影响。交易平台区分成交总额与平台按佣金确认的收入。
- **项目制和专业服务：** 把签约额、在手项目、已完成或验收的里程碑、确认收入和回款沿时间对齐。再看对应的交付工时、外包或直接成本，判断收入增长是否伴随可复制的交付能力和合理的项目贡献。

例如，期初 ARR 为 100，同一批客户期末对应 92，新客户贡献 30，并购并入 18，则期末 ARR 为 140。总额增长 40%，固定客户群 NRR 却是 92%。这两项结果说明的商业问题不同，不能用总额桥接替代客户留存判断。

## 看单位经济与增长可重复性

只有单位经济可能改变当前结论时，先选与客户付费和交付相符的单位，例如付费账户、已交付订单、完成项目或设备运行小时。按同一单位计算实际净收入和能够归属到该单位的直接获客、交付、材料、渠道、售后或退款成本。获客效率影响规模化判断时，把可归因的获客成本与客户产生的毛利贡献和回收时间对照；客户生命周期价值只在同类客户群已有足够续约或复购记录时估算，并说明外推依赖的留存假设。区分毛利、扣除可变成本后的贡献和分摊固定费用后的利润；资料未包含某项成本时，不把部分成本口径说成完整盈利能力。

沿时间、客户群或产品拆分指标，检查增长是否来自同一批客户续约或复购、更多用量、更高价格、新客户、新项目、收购或统计范围变化。只选能区分这些解释的资料：例如高增长是否由单一客户贡献，试点是否转为付费交付，渠道出货是否到达终端，扩容是否抵消流失，毛利变化是否来自组合或投入成本。出现异常时回到原始合同、交易或财务项目核对，并列出仍能解释现象的其他原因。

## 统一可比口径并更新判断

与同行比较时，对齐产品和客户群、收入确认阶段、期间长度、币种、客户群起点、分子分母及统计范围。指标同名不代表计算方法相同：上市公司的“留存率”可能按到期续约金额计算，也可能按固定客户群的前后期年化收入计算。无法按公开定义重算到相同口径时，把它作为方向性参照，不据此排出强弱名次。

最后说明哪些经营事实已经成立、它们支持哪种商业解释、还存在哪些能改变解释的反证或缺口。把结论落实到这条产品线的商业化阶段、增长质量、单位经济或当前风险；只有用户要求初筛或投前判断时，才据此更新投资处理意见。
