# 市场判断指南

交付自行估算的结果时，写出实际采用的公式、口径、期间、单位、关键输入及假设，使他人能够复算。指出会显著改变结果的敏感项及其依据；关键条件不确定时用有依据的范围或情境说明影响，不只交一个点值。

按产品、采购机制和目标期间估算市场，核对需求怎样传导到公司的现实机会。

## 1. 市场数字先分层

任何市场数字都先判断它解释的是哪类问题：

1. 宽泛行业背景：说明一个大行业或主题的发展环境。
2. 产品或服务品类：说明某类产品、材料、设备、软件或服务的总体需求。
3. 应用细分场景：说明特定客户、行业、地区或应用里的需求。
4. 目标产品相关机会：说明公司具体产品或服务可能对应的收入机会。
5. 公司现实可进入的机会：受地区、客户类型、价格带、渠道、资质、认证、产能和交付能力影响的部分。

使用数字前核对：

- 这个数字具体覆盖什么。
- 它和公司产品、客户预算或采购场景有什么关系。
- 它不能说明什么。

## 2. 需求传导

追溯需求怎样传到公司产品。

核对：

- 下游应用或客户需求为什么变化。
- 谁采购、谁使用、谁决策。
- 采购预算来自哪里。
- 目标产品在客户方案中承担什么作用。
- 下游增长会如何影响目标产品用量、单价、采购意愿或替换节奏。
- 这条传导关系是直接、间接，还是目前证据不足。

传导关系不清时，相关市场数字只能支持行业背景判断。

## 3. 市场数字记录

每个市场数字都记录：

- 发布机构。
- 发布日期。
- 地理范围。
- 时间区间。
- 市场定义。
- 币种和汇率口径，如发生换算。
- 数字包含的收入类型：产品、服务、交易额、软件订阅、广告、金融收益、材料、设备或其他。
- 与目标公司产品的关系：直接相关、间接相关、背景参考或待确认。

## 4. TAM/SAM/SOM

只有在用户要求市场空间测算、融资材料、投资判断或商业计划时，才使用 TAM/SAM/SOM。

使用时先说明假设：

- TAM：理论上解决该问题的总需求。
- SAM：公司产品现实可服务的市场。
- SOM：公司在一定时期内可能获得的份额。

数据不足时，先把结果定义为某个期间内的市场收入，再按采购机制选择自下而上的算法。年度支出已经包含一年的购买或订阅，不再乘复购率或更换周期；单次客单价则需要乘该期间内的项目数或购买频次。装机量除以平均更换年限，适用于装机量和更换节奏大致稳定时的稳态年度需求近似。若设备集中在近期装入、存量增长快或已知更换集中在哪些年份，按装机批次及对应寿命分布，或按已知采购计划估算目标期间的替换量。

- **订阅或企业服务：** `目标客户数 x 适用客户比例 x 年合同额`。这是年度合同额机会；续约率影响已有客户收入能否留存，不是把年度市场再乘一次的系数。
- **按次或耗材销售：** `期间内可服务客户数 x 每客购买次数 x 每次购买数量 x 净单价`。若已知每客年支出，可直接乘客户数，不再乘购买次数。
- **耐用品更换：** 稳态近似为 `适用装机量 ÷ 平均更换年限 x 单台价格`，另计新增装机需求时说明是否与替换需求分开。目标期间内的装机或更换节奏明显不均时，按各批设备的装机时间、寿命或已知采购安排估算，不把稳态平均数当作当年预测。
- **项目制采购：** `期间内可服务项目数 x 单项目内目标产品的采购额`。若项目数已经按年度统计，无需再乘更换周期。
- **按抽佣模式经营的平台：** `期间内交易用户数 x 每用户交易频次 x 平均交易额 x 抽佣率`。交易额是平台成交额，不是平台收入；按抽佣方式变现时，抽佣率才把成交额换算为平台收入机会。

估算期间要和输入数字的单位一致，并标明是在算年收入、某一期间的采购额，还是某个时点的存量。市场估算、实际客户机会、订单和收入分别核对。

## 5. 采用节奏

存在市场需求不等于短期收入可实现。需要检查：

- 客户决策和采购周期。
- 切换成本和组织阻力。
- 渠道建设时间。
- 价格接受度和付款周期。
- 现有供应商、品牌或平台锁定效应。
- 合规、资质、交付、售后或生态支持要求。

检查这些因素如何影响公司把需求转成客户导入、订单和收入。

## 6. 常见偏差

市场判断优先避免三类问题：

- 用大行业规模代替公司产品机会。
- 只写市场增长，不写谁采购和为什么采购。
- 把客户认证、产能、交付、渠道或价格限制忽略掉。

修正方式是回到问题：这个市场数字到底解释什么？它和公司产品、客户预算、商业化阶段之间是什么关系？
