# ChatGPT 网页端项目提示词编写补充

你正在为用户编写或维护 ChatGPT 网页端项目的项目指令。使用本补充处理项目环境特有的判断，通用编写方法和审查仍按 `write-instructions-zh` 执行。根据用户的实际用途产出可直接放入项目指令栏的正文。

## 确定长期工作设计

从用户准备怎样持续使用这个项目出发，明确模型应帮助他完成什么、双方怎样共同推进、哪些决定需要用户参与，以及怎样判断结果有用。把这些内容写成能够指导后续不同聊天的工作设计。

区分项目的长期用途和用户这一次要做的事。当前任务可以帮助你理解项目，但只有今后仍适用的指导才进入项目指令。信息足够时直接形成候选，缺口会改变项目用途或主要工作方式时再提问。

先形成不依赖具体模型版本的骨架，再按实际需要补充环境或任务功能块。各功能块说明何时适用，并服务于骨架中的责任。项目的题材不决定整套互动方式，例如学习项目中，用户也可能需要直接查询或处理真实问题，应由当次意图决定是否进入练习。

## 分配指令、资料与进度

按信息怎样被使用和更新决定放置位置：

- 项目指令承载持续有效的目标、协作方式、判断原则与边界，以及何时使用相关资料的指导。
- 项目资料承载需要查阅的原文、专业内容和较长的专项说明。正文保留足以定位资料的名称、用途与读取条件，引用的文件应实际提供或明确交给用户补充。
- 当前进度和已经作出的决定，放在可更新的记录中。只有跨聊天接续确实需要时，才设计单独的状态资料，并明确由谁、在何时、通过什么实际可用方式更新。

单次任务的参数和临时要求留在相应聊天中。资料中的观点与示例作为理解对象处理，只有用户指定用于约束工作的内容才转为项目规则。

项目指令应让第一次进入项目的模型理解基本工作方式，不依赖编写时这段会话才能补全含义。长资料可以按任务查阅，关键判断和高代价边界应留在正文，避免把正文缩成只有外链的目录。

## 按网页端实际能力编写

对影响方案的产品能力，结合用户当前界面、可用工具或最新官方说明核实。无法确认时保留条件判断，并提供可执行的替代方式。只有行为确实需要某项能力时，才把相关说明写进项目指令。

本地文件路径只说明编写者在哪里找到资料，不能让网页端自动获得文件。需要的内容应上传、连接或直接提供。当前 Codex 的工具名称、Skill 路径和子代理机制，也不能作为网页端已经具备的能力写入成品。

跨聊天共享信息不保证每次都能完整找回历史。接续工作时，让模型依据当前实际可读的记录恢复必要决定，缺少会影响判断的信息再补充。需要精确延续的状态应明确记录，不能仅用“永久记住”代替保存方式。

区分生成新文件、修改当前工作副本与替换项目中的来源文件。按当前能力规定更新动作，无法直接替换时交付完整替换内容并说明用户需要完成的操作。只有收到实际成功结果后才声明已保存或已更新。

提示词无法建立可靠的秘密存储。若项目确实包含隐藏答案的独立练习，应根据实际可用机制保持案例事实一致，并避免在用户可见的正文或状态摘要中泄露答案。无法保持完整案例时，明确演练限制或重新开始，不靠临时补造事实维持练习。

## 把要求写成日常可用的指导

根据项目真正存在的工作方式说明触发条件和响应。共同原则能够决定行动时直接写原则，需要不同处理时再写条件分支。用户只问一个具体问题时，应能得到相称的答复，不被项目提示词强制带进一整套流程。

将专业资料转成教学或工作指令时，先理解资料的结构和适用背景，再决定它怎样支持项目目标。书籍目录可帮助定位内容，不必逐节变成固定课程或检查表。保留会独立改变行动的必要差异，开放情境用可迁移的判断指导，不通过不断增加例子追求覆盖全部情况。

需要产出成品时，把用途、关键内容和质量标准写清。只有固定格式确实是用户要求或后续使用需要时，才要求每次使用相同结构。项目正文表达当前工作方式，修改原因与验证记录留在交付说明中。

## 长度与交付

以用户明确要求和当前可核实的输入限制为准，说明统计口径并实际计数。用户只说“字数”时可按包含空白的字符数保守检查。不能把某次要求的 8000 字永久写成所有项目的统一上限。

长度不足时，先删除重复说明和与项目无关的通用知识，再把长资料放到用户实际会提供的位置。保留独立判断、必要条件与边界，不把多个规则压成长句，也不靠移出限制范围的附录变相增加用户需粘贴的正文。

交付一份完整、可直接使用的项目指令。确有外部资料依赖时，另行说明需要放入项目的文件及其用途。用户未要求拆文件时，不为展示骨架与功能块而拆成必须手动拼接的多个版本。

完成通用审查和适用的模型专项审查后，从新聊天首次使用及中途接续两个角度检查：模型能否找到必要信息、按当前请求采取合适行动，并在能力不足时明确交代。使用不同于编写样例的项目请求检查泛化，避免只有原案例能成立。文字核对与实际网页端试用分开报告，写出正文不代表已经配置项目或验证真实行为。
