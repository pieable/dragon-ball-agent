# Codex 提示词的装配与分工

编写或审查 Codex 的全局规则、项目规则、角色和 Skill 时，先确定目标 agent 实际收到哪些内容，再决定规则放在哪里。以下区分长期有效的分工方法与需要按当前宿主核实的加载行为。

## 哪些内容在什么时候进入上下文

| 内容 | 通常的进入方式 | 编写时需要注意什么 |
| --- | --- | --- |
| 宿主基础指令、工具定义、权限与环境说明 | 宿主在请求中组装，部分工具按需提供 | 先利用已有规则和能力；本地文件不能自行增加权限或工具 |
| 全局 AGENTS.md | 按 Codex 配置发现并加入工作上下文，主 agent 和子 agent 都可能获得同一份全文 | 共同原则可由全局文件承载；主 agent 专属规则按其适用对象执行，不能因子 agent 看见全文就把主职责交给它 |
| 项目及目录 AGENTS.md | 根据工作目录、项目根、覆盖文件与大小限制发现 | 只包含适用范围内的规则；项目其他目录和索引指向的资料不会因此全部载入 |
| 可调用 agent 的名称、描述与参数 | 以角色目录或委派工具说明提供给调用者 | 描述负责让调用者知道何时选它、能得到什么；不能把唯一的调用条件藏在该角色正文里 |
| 被选角色的 developer_instructions | 创建对应子代理时进入该子代理的指令 | 写它怎样完成职责；主 agent 不因看见角色描述就自动读过其正文 |
| Skill 名称、描述、路径 | 可用 Skill 目录通常先进入上下文 | 描述负责触发与区分用途，不替代工作方法；目录受发现、开关及宿主限制影响 |
| SKILL.md 正文及引用资料 | 选用后读取或由相应调用机制提供，引用资料按需读取 | 必需方法放正文，条件性细节由正文给出入口；被提到或安装不等于已经读到 |
| 本次委派、继承的对话、工具结果 | 随委派请求、历史选择及后续操作进入 | 委派交代当前目标、有效决定与材料入口；不能假定父 agent 已读的文件或完整历史自动可见 |

“谁能读到”与“谁负责执行”分开判断。全局 AGENTS 可以同时包含主 agent 专属段和主子 agent 共用段。角色正文只补充该角色需要的指导，不能因为它能读到主 agent 的组织规则，就擅自承担用户交流或整体取舍。

消息优先级也不同于组织上的上下级。文件叫 Base、全局或项目，不决定它在模型请求中的消息层级；需要判断冲突时核对实际承载消息和宿主规则。这里的表格说明可见性，不另行定义优先级。

## 按阅读者放置规则

共同的事实标准、授权原则、表达方式和协作约定优先由共同读取的 AGENTS 承载。角色保留职责、独有方法、允许自主决定的事项，以及职责特有的交付要求。不能仅因语句相似就删除：例如代码评审的只读、视觉验收的截图坐标证据，以及执行角色是否允许再委派，都可能是角色边界。

角色描述和 Skill 描述是开始工作前的选择入口，应让调用者区分相邻能力。正文负责执行。主 agent 需要知道什么情况下调用某角色，但该角色才需要知道具体怎样完成时，把调用条件放描述或调度规则，把操作方法放角色正文。

Skill 保存可复用的专门方法，角色说明在什么任务中使用它以及产出怎样被接收。需要依赖 Skill 而下属未必看见目录时，委派提供准确入口并要求读取，或提供本任务必要的指导。不要把完整 Skill 复制进每个角色，也不要只写一个它无法定位的名称。

项目规则保存当前项目约束和资料入口。本次委派保存这次责任、有效决定、输入、允许动作和完成依据。用户本次没有确定的实现细节，不因为某份角色模板要求“完整合同”就变成必须由上级预先设计的内容。

## 修改前怎样核实

先查看当前可见的 Skill 目录、角色工具说明、适用 AGENTS 和目标角色正文。需要删除重复或迁移规则时，核对接收方确实得到承接内容。路径、文件存在、配置字段和 README 都只是证据的一部分，不能替代实际加载结果。

可用时检查当前宿主的请求记录或提示输入诊断，区分描述、正文、工具结果和继承历史。`codex debug prompt-input` 可核对当前 CLI 的消息装配，但不单独证明 Desktop 子代理获得相同内容，也不包含所有可能的请求层信息。用户要求不使用子代理时，使用已有记录和不调用模型的诊断，明确未做新的行为测试。

检查 AGENTS 的发现范围、覆盖文件和长度限制；检查 Skill 的启用状态、目录显示与正文读取；检查角色描述的可见性、角色正文的实际加载和对话继承范围。只核查与本次修改有关的部分，已确认且未变化的加载关系直接沿用。

维护说明应指向当前实际加载的来源。几个角色曾共享同一前缀，后来已经分别修改时，不能继续要求批量同步为完全相同的正文。保留对照与修改原因，但历史规则不作为当前装配指令。
