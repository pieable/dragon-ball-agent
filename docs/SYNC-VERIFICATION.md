## 同步引擎

CLI 默认 preview。显式 apply 使用完整候选哈希、目标绑定和安装就绪状态，拒绝冲突或未完成适配。状态目录独立保存逐项备份、候选及事务记录；中断后 inspect 可查看实际文件位于修改前、修改后还是发生用户改动，再明确回退。

```powershell
python tools/sync_engine.py --source <候选目录> --target <安装目录> --state <私有状态目录> --manifest <候选目录>/candidate-manifest.json
```

当前完整体系候选仍标为未部署就绪，不运行真实安装。同步写入和回退行为使用独立临时目标验证。
