# 历史与本次发布

## 2026-09-15：收敛公开发布范围

按用户确认，当前发布保留全局规则、10 个角色和 12 个 Skill。直播剪辑、MarkItDown、Playwright、中文简历优化四个专项 Skill 移出当前仓库目录。本机安装不变，已发布版本仍保留在 Git 历史中。同步更新中英文目录、安装依赖说明与第三方文件索引。

## 2026-09-15：同步全局提示词体系

本次以维护环境的全局 `AGENTS.md`、10 份独立角色 TOML 和当前自定义 Skills 为发布来源。项目专属直播规则、用户配置、会话、记忆、缓存和个人联系图片不属于发布内容。

### 当前结构

- `global/`：共同工作方式、逐步计划、投入判断和委派边界。
- `agents/`：自包含角色 TOML。
- `skills/`：任务方法及其引用资源。
- `examples/`、`INSTALL.md`：安装与项目配置示例。
- `docs/`：发布说明及维护记录，不作为全局指令安装。

产品方法负责形成和更新产品结果与成功标准，代码方法负责实现行为与工程验收，研究方法负责提供领域框架、候选和证据。执行计划随理解与结果逐轮形成，编号以独立任务为范围。研究优先级同时考虑成熟证据、契合度、模块价值和关键决策，不要求对全部候选逐个深挖。

### 旧结构去向

[上一版完整快照](https://github.com/pieable/dragon-ball-agent/tree/0d16227b1076fd76d0a4417b35528f48d38a1787)保留在 Git 历史中，可回看旧 `prompt-lab/`、`hooks/`、共享 Base 和 `batch-execution`。本次将它们移出当前文件树，避免旧安装路径与现行规则混用。没有改写历史提交。

已有安装应检查是否仍启用了旧 `model_instructions_file`、Root `developer_instructions` 镜像或 Hook。先确认是否含用户后来新增的独立要求，保留有效内容，再移除已被当前规则取代的装配。不能直接清空接收环境的这些字段。

### 验证边界

发布副本仅作必要的便携性和隐私调整：MarkItDown 命令改为定位已安装程序，三份结构说明的本机绝对路径改为同目录引用，简历 Skill 的个人联系图片及对应段落不发布。Frontend Design 补齐对应官方版本的许可证。全局生效提示词不因这些打包调整而改写。部分维护日志提到的本地备份和实验路径仅是历史出处，不是运行依赖，未随包发布。

发布检查覆盖文件差异、角色语法、Skill 元数据、引用完整性及敏感内容风险。它不证明全新宿主已加载，也不证明这套方法必然提高每个项目的最终质量。行为效果需要实际任务持续验证。
