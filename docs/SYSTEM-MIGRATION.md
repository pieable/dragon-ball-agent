## 后续批次

1. 个人 Skills 的正文、引用文件、脚本与模板逐项审查后迁入。私人学习档案、历史会话和不可再分发的原文不进入公开源；保留相应本地扩展接口与来源说明。

## 保存与发布边界

迁移前已在仓库之外保存实际运行文件、校验值和各组件 Git 历史。每个阶段独立提交，保留原始工作区的未提交变化。公开仓库不导入这些私有备份。

不纳入 auth、密钥、环境变量实值、账户与浏览器状态、会话、记忆、个人任务、数据库、缓存、日志、机器信任配置及完整私人历史。发布前检查整个新增文件集，而非仅依赖 gitignore。

迁移完成后，仓库为可分享组件的维护源，本机为部署目标。本机临时修改先比较并回收，不做相互覆盖的双向同步。
